# 🚨 急症处置速查

<Danger title="先读这条：兔兔是猎物动物，会隐藏病情">

兔兔本能隐藏疼痛和虚弱（避免被捕食者发现）。**等你看到"明显不对"时，病情往往已经很重**。任何怀疑都应优先联系**懂兔的异宠兽医**，不要因网络信息延误就诊。

本站所有"家庭处置"步骤都只是**送医前/兽医电话指导下的稳定措施**，**不能替代兽医诊断和治疗**。

</Danger>

## 一、最重要的红线：12 小时

<VetCheck>

- 兔兔**停止进食或停止排便达 12 小时或更久**——这是 House Rabbit Society 明确定义的 **EMERGENCY**<cite><a href="#ref1">[1]</a></cite>
- 任何**水样/血性腹泻**（尤其幼兔）
- **张口呼吸**、**抽搐**、**昏迷**
- **后腿拖行/瘫痪**（疑似脊柱骨折）
- 误食有毒植物/异物
- **持续出血**按压 10–15 分钟不止

</VetCheck>

## 二、养兔家庭必备急救包

### A 级：家庭非处方常备（安全，送医前可作应急）
- **婴儿西甲硅油（Simethicone）** —— 无色无味型，用于胀气
- **Oxbow Critical Care** 或 Sherwood Recovery Food —— 强制喂食
- **无味 Pedialyte** —— 电解质补充
- **数字温度计** + 水基润滑剂（正常体温 38.3–39.4°C / 101–104°F）
- **无针头注射器**（1 mL、5 mL、35 mL 导管尖各备）
- **生理盐水**、**纱布**、**Nolvasan（氯己定）**
- **普通 Neosporin/Polysporin**（**不含**止痛/皮质类固醇成分）
- **止血粉 / 玉米淀粉**（指甲出血应急）
- **毛巾**（保定用）、**加热垫/冰袋**（**必须先量体温再用**）

### B 级：非处方但需谨慎
- **Bene-Bac Plus 凝胶**（短期备用益生菌）
- **Terramycin 眼膏**（浅表眼感染应急）

### C 级：必须兽医处方（**绝不要自行使用**）
- 促动力药（Metoclopramide）、止痛药（Meloxicam）
- 球虫药（Toltrazuril/Diclazuril）、驱虫药（Fenbendazole）
- 皮下输液（LRS）

### D 级：明确禁忌（不要进你家）
- ❌ **猫用化毛膏（Petromalt/Laxatone）** —— 详见[化毛膏争议](../supplies/hairball-remedy)
- ❌ **含止痛/皮质类固醇的 Neosporin Plus** —— 类固醇对兔严重免疫抑制
- ❌ **人用运动饮料（佳得乐等）** —— 含糖添加剂过高
- ❌ **口服青霉素/阿莫西林、头孢类** —— 对兔可致命<cite><a href="#ref2">[2]</a></cite>

## 三、家庭急救通用流程

<FirstAidStep :num="1" title="保持冷静，评估兔兔状态">

兔能感知饲主恐慌，会加重应激。先观察：是否在呼吸？是否反应迟钝？是否有明显外伤/出血？测体温。

</FirstAidStep>

<FirstAidStep :num="2" title="立即联系异宠兽医">

电话说明症状、持续时间、兔兔年龄体重。**许多急症的黄金处置窗口只有几小时**。

</FirstAidStep>

<FirstAidStep :num="3" title="送医前的稳定">

根据本站对应急症章节做家庭稳定（如胀气给西甲硅油、中暑降温、出血按压）。**所有稳定措施同步进行送医，不要替代就诊**。

</FirstAidStep>

<FirstAidStep :num="4" title="收集信息给兽医">

记录症状开始时间、最近饮食排便变化、近期应激事件、误食物品（带包装/照片）、粪便样本。

</FirstAidStep>

## 四、急症速查目录

| 急症 | 关键信号 | 紧急程度 |
|---|---|---|
| [胃肠停滞（胀气/拒食）](./gi-stasis) | 不吃不拉、蜷缩、磨牙、粪便变小 | **12 小时不吃不拉 = 急诊** |
| [腹泻](./diarrhea) | 水样/黏液/血性粪便 | 幼兔数小时可致命 |
| [中暑](./heatstroke) | 耳朵烫、呼吸急促、张口呼吸、抽搐 | 致死体温 >40.5°C |
| [外伤出血](./wounds) | 出血、咬伤、撕裂 | 按压 10–15 分钟不止 → 急诊 |
| [骨折](./fractures) | 不敢着地、变形、后腿瘫痪 | 任何怀疑骨折 = 急诊 |
| [抽搐/癫痫](./seizures) | 全身抽搐、意识丧失、头部倾斜 | 首次发作立即就医 |
| [呼吸问题](./respiratory) | 打喷嚏、脓鼻涕、张口呼吸 | 张口呼吸 = 濒死信号 |
| [球虫病](./coccidiosis) | 幼兔腹泻/便血/腹胀 | 幼兔头号杀手 |
| [毛球症](./hairball) | 实为 GI Stasis 表现 | 与 GI Stasis 同样处理 |
| [中毒/误食](./poisoning) | 拒食、流口水、抽搐、口腔肿胀 | **禁止催吐**，立即就医 |

## 五、几条致命误区（必须记住）

<Danger title="这些操作会害死兔兔">

1. **中毒后催吐** —— 兔生理上无法呕吐，催吐会导致误吸窒息<cite><a href="#ref3">[3]</a></cite>
2. **自行夹板固定骨折** —— 非专业夹板会加重损伤<cite><a href="#ref4">[4]</a></cite>
3. **GI 梗阻时强制喂食** —— 会加重梗阻
4. **给兔用猫化毛膏/泻药** —— 油基润滑剂使毛球防水、更难排出<cite><a href="#ref5">[5]</a></cite>
5. **用含皮质类固醇的外用药**（如 Neosporin Plus）—— 严重免疫抑制<cite><a href="#ref2">[2]</a></cite>
6. **把"未食用的盲肠便"当腹泻过度治疗** —— 两者处置完全不同
7. **"还能吃一点就再观察"** —— 兔会忍痛进食到无法忍受，发现拒食时往往已很重
8. **用剩的人药/猫狗药** —— 许多常用抗生素对兔致命

</Danger>
