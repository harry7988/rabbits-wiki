# 🚨 中毒 / 误食

<EmergencyCard />

## 一、生死攸关的事实

<Danger title="兔子生理上无法呕吐 —— 绝对禁止催吐">

兔解剖学上贲门括约肌强有力，且缺乏呕吐反射。详见 [兔不能做的几件事](../digest/key-traits)。

因此<cite><a href="#ref1">[1]</a></cite>：
- **绝对禁止催吐**（对兔既无效又危险，会导致误吸/窒息）
- **不要自行给活性炭**（除非兽医指示）
- **不要给水/牛奶**（除非兽医指示）
- **不要等症状出现才就医**——毒物代谢迅速，延误常致命

</Danger>

## 二、中毒症状

- 拒食、流口水、嗜睡
- 腹泻/便血
- **抽搐、震颤、瘫痪**
- 呼吸困难、心率异常
- 口腔刺激/肿胀

## 三、家庭紧急处置

<FirstAidStep :num="1" title="立即移除剩余的有毒物质">

收走剩余植物/食物并装袋（便医鉴定），检查口腔有无残留。

</FirstAidStep>

<FirstAidStep :num="2" title="收集关键信息（极重要）">

- **植物名称/照片**
- 误食物的**活性成分**（药品/化学品包装）
- **估计摄入量**
- **摄入时间**

</FirstAidStep>

<FirstAidStep :num="3" title="立即联系兽医/宠物毒物热线">

- 国内：当地异宠急诊兽医
- 美国：Pet Poison Helpline 855-764-7661
- 把上述信息告诉兽医

</FirstAidStep>

<FirstAidStep :num="4" title="不要催吐、不要给活性炭、不要给水/牛奶">

兔无法呕吐，催吐手段无效且有害；活性炭与水/牛奶都可能加速毒素吸收——除非兽医明确指示，否则不给。

</FirstAidStep>

<FirstAidStep :num="5" title="立即送异宠兽医">

带上误食物的包装/照片/剩余部分。

</FirstAidStep>

## 四、常见有毒植物（家养/户外常见）<cite><a href="#ref2">[2]</a></cite><cite><a href="#ref3">[3]</a></cite>

### 室内
- **百合科（Lily）**、**滴水观音**、**黛粉叶**、**常春藤**、**绿萝**、**芦荟**

### 户外
- **杜鹃（Azalea）**、**毛茛（Buttercups）**、**毛地黄（foxglove）**、**毒芹（hemlock）**、**龙葵（nightshade）**、**狗舌草（ragwort）**、**罂粟（poppy）**、**常春藤（ivy）**、**蓝铃花（bluebells）**

### 球根类
- **大多数球根类植物有毒**（郁金香、水仙、洋葱等）

### 其他
- **果树种子/果核**（苹果籽、杏核等含氰苷）

<Info title="饲主责任：提前核查所有家养植物">

养兔前应**逐一核查**家中所有植物是否对兔有毒。Cornell 大学维护着权威的有毒植物数据库<cite><a href="#ref2">[2]</a></cite>。

</Info>

## 五、致命误区

<Danger>

1. **尝试催吐** —— 兔生理上无法呕吐，催吐危险
2. **『等等看』** —— 毒物代谢迅速，延误就医常致命
3. **不知道家里植物是否有毒** —— 饲主应提前核查
4. **给牛奶『解毒』** —— 兔乳糖不耐受，且牛奶会加速某些毒物吸收

</Danger>

## 六、何时必须立即就医

<VetCheck>

- **任何已知或疑似的毒物/异物误食**——不要等症状
- 已出现任何中毒症状（拒食、抽搐、流口水等）

</VetCheck>
