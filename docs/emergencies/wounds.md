# 🚨 外伤出血

## 一、伤口分类

- **轻微出血**：剪指甲误伤血线、浅表划伤
- **深部伤口/咬伤**：动物咬伤、深部撕裂，可能伤及深层组织
- **持续出血**：按压 10–15 分钟仍不止
- **脓肿**：皮下肿胀、温热、疼痛，可能破溃流出**浓稠干酪样脓液**（兔子脓液特性）

## 二、家庭紧急处置

<FirstAidStep :num="1" title="止血">

- **按压法**：用干净纱布/毛巾**直接按压几分钟**至血块形成
- **指甲出血**：将**止血粉**直接按压在指甲尖端
- **家用替代品**：玉米淀粉、普通面粉、小苏打粉；甚至可将指甲末端按在一块肥皂上
- **严重出血**：QuikClot 或 Celox 等止血剂

</FirstAidStep>

<FirstAidStep :num="2" title="清洁伤口">

- **生理盐水/兽医洗眼液**冲洗伤口或眼睛
- **Nolvasan（氯己定/洗必泰）**轻轻清洗伤口周围（HRS 推荐）<cite><a href="#ref1">[1]</a></cite>
- **双氧水**：可用来『清洁毛发上的血迹』或检测尿中是否含血（遇血起泡）；但**不推荐直接用于深部伤口冲洗**（会损伤组织）

</FirstAidStep>

<FirstAidStep :num="3" title="涂药">

涂抹**极薄一层普通 Neosporin / Polysporin**（三联抗生素软膏）<cite><a href="#ref1">[1]</a></cite>。

<Danger title="必须选『不含止痛成分』的版本">

Neosporin Plus 或任何**含皮质类固醇（cortisone/氢化可的松）**的产品——HRS 用三个感叹号警告『!!!』——**类固醇对兔免疫抑制严重**。

</Danger>

</FirstAidStep>

<FirstAidStep :num="4" title="包扎与限制活动">

用 VetWrap/CoFlex 自粘绷带。保持兔安静，防止再出血。保持环境清洁。

</FirstAidStep>

## 三、何时必须立即就医

<VetCheck>

- **按压 10–15 分钟仍不止血**
- **深部咬伤**（特别是猫咬伤，感染风险极高）
- 大面积撕裂伤
- **怀疑脓肿**（无论是否破溃）——兔脓液浓稠干酪样，家庭引流极困难，需兽医麻醉下切开清创 + 抗生素<cite><a href="#ref2">[2]</a></cite>
- 任何**面部/口腔伤口**
- 出现感染征象：红肿热痛、精神萎靡、拒食

</VetCheck>

## 四、常见误区

<Warning>

1. **使用 Neosporin Plus 或任何含皮质类固醇的外用药** —— HRS 三叹号警告，类固醇对兔严重免疫抑制<cite><a href="#ref1">[1]</a></cite>
2. **挤压或用力擦洗脓肿** —— 会使感染扩散
3. **尝试自行引流脓肿** —— 兔脓液特性（浓稠、干酪样）使家庭引流几乎不可能成功
4. **使用双氧水直接冲洗深部伤口** —— 会破坏健康组织
5. **忽视猫咬伤** —— 猫口腔细菌对兔极危险，必须立即就医 + 抗生素

</Warning>

<Info title="兔脓肿为什么特别难处理">

兔的脓液与猫狗不同——**浓稠、干酪样、不流动**，被厚包膜包裹。这种特性意味着：(1) 家庭挤压/引流无效；(2) 抗生素难以渗透；(3) 常需外科清创 + 长期抗生素。任何皮下肿胀都要警惕脓肿。

</Info>
