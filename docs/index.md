## 🐇 为什么有 rabbits.wiki

兔兔是会**隐藏疼痛**的动物，病情进展极快——一顿没吃好可能就是致命急症的开端。市面上的养兔信息鱼龙混杂，很多"经验"以讹传讹（比如给兔用猫化毛膏）。

rabbits.wiki 想做的是：**把每一条建议都溯源到权威兽医来源**，让每一个兔主人都看得懂、信得过、用得上。
