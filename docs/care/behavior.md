# 🎭 兔兔行为解读

读懂兔兔的行为，是判断它**情绪、健康、需求**的关键。

## 一、开心 / 放松的信号

| 行为 | 含义 |
|---|---|
| **Binky（蹦跳扭身）** | 最高级别的开心！兔在空中扭身/踢腿，表示极度快乐 |
| **Flop（弗洛彭，突然侧倒/翻倒）** | 极度放松和安全的信号（新手常误以为昏倒）|
| **轻柔磨牙（purr-like）** | 类似猫打呼，满足、享受 |
| **趴平、后腿伸展** | 完全放松 |
| **舔你/舔同伴** | 信任、亲密（梳毛是兔兔的社交最高礼） |
| **追着你跑** | 邀请互动或讨食 |

<Info title="Binky 是养兔人最幸福的瞬间">
看到兔兔 binky（空中扭身跳跃），说明它**身心健康、环境满意**。这是兔主人的终极成就。
</Info>

## 二、警告 / 不满的信号

| 行为 | 含义 | 应对 |
|---|---|---|
| **跺脚（thump）** | 警告、恐惧、不满 | 找出刺激源（声音、捕食者气味），安抚 |
| **轻咬** | "别这样" / 抗议 | 停止当前动作 |
| **用力咬（出血）** | 严重恐惧/疼痛 | 后退，给空间，检查是否受伤 |
| **喷尿** | 领地标记/求偶（多见未绝育公兔）| 绝育能改善 |
| **下巴蹭（chinning）** | 用下巴气味腺标记"这是我的" | 正常行为 |
| **用鼻推你的手** | "摸我"或"走开"，看上下文 | 看是凑近还是后退 |

## 三、健康警报（行为异常）

<Danger title="这些行为变化是疾病信号">
兔会隐藏病情。行为变化往往是**最早**的疾病线索：

- **突然停止 binky / 不愿动** → 可能疼痛（关节、牙、腹）
- **蜷缩成球、躲藏** → 疼痛/应激，可能是 [GI Stasis](../emergencies/gi-stasis)
- **大声磨牙（区别于轻柔磨牙）** → **疼痛信号**，急症
- **歪头 / 转圈 / 眼球震颤** → *E. cuniculi* 或前庭疾病，[急症](../emergencies/seizures)
- **流口水** → 牙病
- **排便习惯改变** → 消化问题
- **不再用厕所** → 可能尿路/关节疼痛
- **攻击性突然增强** → 激素（未绝育）或疼痛
</Danger>

<Info title="区分『轻磨牙』和『大声磨牙』">
- **轻柔、规律、伴随放松姿态** = 满足
- **大声、用力、伴随蜷缩/弓背** = 疼痛（急症）

这是养兔人必须学会的关键区分。
</Info>

## 四、繁殖/激素相关行为（绝育后大部分消失）

- 假性妊娠（母兔拔毛筑巢）
- 喷尿标记
- 骑跨（建立支配）
- 圈地（绕着人或物体转圈哼叫）
- 攻击性

详见[绝育专题](./spay-neuter)。

## 五、有趣的兔兔行为

| 行为 | 含义 |
|---|---|
| **挖洞/刨地** | 天性（野生兔住洞穴）|
| **啃家具/电线** | 磨牙 + 探索。**必须提供电线保护套和啃咬玩具** |
| **throw toys（甩玩具）** | 玩耍、解闷 |
| **趴在另一只兔身上** | 支配（合笼中） |

## 六、理解兔兔的"语言"

兔兔不会说话，但通过行为能告诉你很多。**最好的养兔人不是让兔听话的人，而是学会读兔的人**。
