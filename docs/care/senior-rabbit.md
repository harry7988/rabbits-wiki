# 🧓 老年兔照护（5+ 岁）

<Info title="『老年』因品种而异">
小型兔（如荷兰侏儒）5–6 岁进入老年；大型兔（如新西兰白兔、Flemish Giant）4–5 岁即算老年。寿命通常 8–12 年，照顾良好的兔可达 12+<cite><a href="#ref1">[1]</a></cite>。
</Info>

## 一、老年兔的常见问题

### 关节炎（极常见）
<Danger title="关节炎是老年兔最常见的隐藏问题">
- 表现：不愿动、不愿跳跃、不愿用高处厕所、梳毛困难（导致 dirty bottom）
- **隐蔽危险**：不愿动 → 肠蠕动减慢 → GI Stasis
- 梳毛困难 → 毛堆积 → 蝇蛆病风险

必须兽医诊断。止痛药（如 Meloxicam，**兽医处方**）能显著改善生活质量<cite><a href="#ref2">[2]</a></cite>。
</Danger>

### 肌肉萎缩 / 体重下降
- 每周称重，**下降是警示**
- 可能需要调整饮食（增加易消化的营养）

### 牙病加重
- 老年兔牙病高发（牙根脓肿、过度生长）
- 兽医每年检查数次
- 流口水、拒食、体重下降是信号

### 视力 / 听力下降
- 白内障（老年兔常见）
- 提供稳定环境，不要随意移动家具

### 认知下降
- 部分老年兔会出现迷茫、日夜颠倒
- 保持日常规律

## 二、老年兔饮食调整

<Warning title="不要自动换成高营养饮食">
老年兔饮食要按**个体**调整：

- **维持提摩西为主**（无限量）
- **体重下降者**：可少量补充苜蓿或燕麦草（兽医指导下，监测膀胱泥沙）
- **关节问题者**：维持健康体重更重要（肥胖加重关节）
- **牙齿问题者**：提供更软的第二/三茬牧草、蔬菜切小块
</Warning>

## 三、环境调整

| 调整 | 原因 |
|---|---|
| **低边厕所/笼** | 关节炎兔进高处困难 |
| **防滑地毯/瑜伽垫** | 关节兔在光滑地面会劈叉受伤 |
| **降低跳台高度** | 关节兔跳跃危险 |
| **温暖环境** | 关节炎怕冷 |
| **食物/水靠近休息处** | 减少移动负担 |

## 四、定期体检（更频繁）

<FirstAidStep :num="1" title="每 6 个月一次兽医体检">
年轻成兔每年一次，老年兔建议**每 6 个月**。
</FirstAidStep>

<FirstAidStep :num="2" title="血检/影像">
年度血检能早发现肝肾问题。X 光能发现关节炎、肿物。
</FirstAidStep>

<FirstAidStep :num="3" title="每周称重 + 记录">
体重趋势是疾病最早信号。
</FirstAidStep>

## 五、临终关怀（诚实但重要的内容）

<Info title="当兔兔进入生命末期">
- 与兽医坦诚讨论生活质量（quality of life）
- 关注：是否仍在享受食物、是否疼痛可控、是否能维持基本卫生
- 必要时与兽医讨论**人道安乐**——这是负责任的爱，避免无意义的痛苦
- 兔兔不会"表现疼痛"，所以生活质量判断需要细心观察
</Info>

## 六、关键提醒

老年兔护理核心：**早发现、早干预、维持生活质量**。关节炎止痛能逆转很多"老年衰退"——很多被以为"老了就这样"的兔，其实是疼痛。
