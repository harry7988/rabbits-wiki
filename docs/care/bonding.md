# 🐰🐰 合笼（Bonding）

<Info title="兔兔是群居动物，强烈建议成对饲养">
经过良好合笼的兔伴能带来：
- 互相梳毛、温暖
- 减少孤独应激
- 共同探索时更自信
- 整体幸福感更高
</Info>

## 一、前提：先绝育

<Danger title="未绝育的兔绝对不能合笼">
- 两只会打架致重伤甚至死亡
- 公兔会持续骚扰母兔
- 假性妊娠、领地喷尿标记

**两只兔都必须在合笼前**完成绝育，并等待激素稳定（绝育后 **4–6 周**）<cite><a href="#ref1">[1]</a></cite>。
</Danger>

## 二、合笼是高风险过程，需要耐心

<Warning title="兔子有强烈领地意识">
把两只陌生兔直接放一起 = 几乎必定打架。合笼必须**循序渐进**，整个流程可能 2 周–数月。
</Warning>

## 三、合笼流程

<FirstAidStep :num="1" title="并列笼子（1–2 周）">
两只兔分笼但能看见闻到对方。**留出一定距离**避免隔着笼子咬。让它们习惯彼此的存在。
</FirstAidStep>

<FirstAidStep :num="2" title="交换 litter box / 玩具">
每天交换它们用过的物品，让气味混合。
</FirstAidStep>

<FirstAidStep :num="3" title="中立空间短时接触">
选一个**两只都没去过**的房间（中立地）。每次 10–15 分钟，**人在场全程监督**。
</FirstAidStep>

<FirstAidStep :num="4" title="观察合笼行为">
- ✅ **正向信号**：互相闻、平行趴、轻舔、模仿动作
- ⚠️ **警告信号**：骑跨（建立支配，可接受短暂）、轻咬
- 🚨 **立即分开**：追咬、拔毛、滚成球打架、"龙卷风"式缠斗

打架时**用扫帚或毛巾隔开**，不要徒手（兔咬伤严重）。
</FirstAidStep>

<FirstAidStep :num="5" title="逐步延长时间">
从 15 分钟 → 1 小时 → 半天 → 全天。一旦它们一起趴着梳毛，基本成功。
</FirstAidStep>

<FirstAidStep :num="6" title="共同笼">
最后一步：清洗笼子消除原兔气味，**同时**放入两只兔。
</FirstAidStep>

## 四、合笼失败的常见原因

| 原因 | 解决 |
|---|---|
| 未绝育/激素未稳定 | 等 4–6 周 |
| 性格不合 | 不是所有兔都能合（可考虑第三只或单身） |
| 空间太小 | 中立地要够大，有遮蔽处供躲避 |
| 太快太急 | 退回上一步 |
| 健康问题（疼痛兔易怒） | 先体检 |

## 五、什么时候放弃？

- 数月持续打架、流血受伤
- 一只长期应激、拒食、抑郁
- 这时候**单只饲养 + 充足人类陪伴**也 OK

<Info title="三只或以上的合笼更复杂">
群养可以，但合笼流程更复杂、领地问题更多。新手建议从 2 只开始。
</Info>
