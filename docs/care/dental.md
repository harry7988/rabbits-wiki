# 🦷 牙齿健康（牙病是急症的隐性诱因）

<Info title="为什么单独讲牙齿？">

牙病是兔兔**胃肠停滞（GI Stasis）的头号隐性诱因**——牙痛让兔不愿咀嚼牧草 → 肠蠕动减慢 → GI Stasis。很多主人以为兔"忽然不吃"是消化问题，根源其实在牙。

而预防牙病的唯一有效方法，就是**吃草**。这就是为什么本站反复强调"无限量长牧草是养兔第一法则"——它同时解决消化 + 磨牙两个最关键的健康问题。

</Info>

## 一、兔牙的解剖（与人类/猫狗的根本差异）

### 1. 终生生长

兔牙**终生持续生长**，速率约 **2 mm/周**<cite><a href="#ref1">[1]</a></cite>。这与人类（换牙后恒牙不再长）和猫狗完全不同。

兔的齿式：**2 (I 2/1, C 0/0, P 3/2, M 3/3) = 28 颗恒齿**<cite><a href="#ref2">[2]</a></cite>：
- **门齿（incisors）**：上 4 颗（一对大门齿 + 后方一对"钉齿"peg teeth，这是兔与啮齿类的关键区别）、下 2 颗
- **臼齿（molars/premolars）**：用于研磨食物

所有牙齿均为 **elodont（开放根）+ aradicular hypsodont（无真正牙根、长冠）**——意味着它们像啮齿类门齿一样会一直长<cite><a href="#ref2">[2]</a></cite>。

### 2. 为什么必须靠"吃草"磨牙

兔的上下臼齿在咀嚼时会产生**横向研磨运动**（side-to-side），这种研磨需要**粗长纤维**（牧草的茎）来提供足够的摩擦力。

颗粒粮、兔粮粉末、柔软蔬菜**无法提供这种横向研磨**——它们被垂直咬碎就吞下了，不磨损臼齿<cite><a href="#ref3">[3]</a></cite>。

<Warning title="颗粒粮不能代替牧草磨牙">

很多人以为"兔粮营养全，可以代替草"。**错**。

- 兔粮的热量、维生素可以做到和牧草一样
- 但兔粮颗粒**太小、太脆**，兔用垂直咬合力咬碎就吞，**不产生横向研磨**
- 结果：吃兔粮的兔，臼齿照常过度生长 → 尖刺 → 刺入颊黏膜/舌头 → 疼痛性溃疡 → 拒食 → GI Stasis

**这是为什么"无限量长牧草"没有例外、不可替代。** 详见[后肠发酵原理](../digest/hindgut-fermentation)。

</Warning>

## 二、磨牙的良性循环 vs 牙病的恶性循环

### ✅ 良性循环（吃草充足的兔）

```
吃长牧草 → 横向研磨 → 臼齿正常磨损
   ↑                          ↓
持续咀嚼 ← 疼痛正常 ← 牙齿长度稳定
```

### 🔴 恶性循环（缺草/只吃兔粮的兔）

```
缺长纤维 → 臼齿磨损不足 → 过度生长
                              ↓
                        形成尖锐尖刺（spurs）
                              ↓
                        刺入颊黏膜/舌头
                              ↓
                        疼痛性溃疡
                              ↓
                        不愿咀嚼（尤其牧草）
                              ↓
                        只挑软食/兔粮 ← 进一步减少研磨
                              ↓
                        胃肠蠕动减慢
                              ↓
                        🚨 GI Stasis（致命急症）
```

## 三、常见牙病

### 1. 错颌畸形（Malocclusion）

**门齿或臼齿不能正确咬合**，导致：
- 门齿：弯曲过度生长（"龅牙"），可能刺穿上唇/下颚
- 臼齿：尖刺（spurs/points）刺入软组织

**原因**<cite><a href="#ref1">[1]</a></cite>：
- **获得性**（最常见）：饮食缺纤维、磨损不足
- **先天性**：遗传性下颌对齐不良（侏儒品种高发）

### 2. 牙根脓肿（Tooth Root Abscess）

**下颌/上颌的牙根感染化脓**，形成：
- 面部/下巴**可触及的肿块**（凹凸不平）
- 脓肿内是兔特有的**浓稠干酪样脓液**（不流动，难引流）

<Warning title="牙根脓肿极难治疗">

兔脓肿的特性（浓稠、干酪样、被厚包膜包裹）意味着：
- 家庭引流几乎不可能
- 抗生素难以渗透
- 常需外科清创 + 长期抗生素（数月）
- 复发率高

**任何下巴/面部肿胀都要立即就医**。详见[外伤/脓肿处置](../emergencies/wounds)。

</Warning>

### 3. 获得性牙病（Acquired Dental Disease, ADD）

成年兔因长期饮食不当累积的综合性牙病：臼齿尖刺 + 牙根拉长 + 牙齿角度改变 + 脓肿<cite><a href="#ref2">[2]</a></cite>。

### 4. 鼻泪管阻塞（牙病连累眼睛）

兔的**牙根与鼻泪管解剖位置相邻**。上颌臼齿牙根感染会**压迫/阻塞鼻泪管** → 表现为：
- 持续流泪、眼分泌物
- 结膜炎反复发作

<Info title="眼病反复？查牙！">

兔的眼部问题**多数根源在牙齿**。表面滴眼药水治标不治本。任何持续或反复的眼部问题，都必须由兔科兽医检查牙齿。详见[常备药品·Terramycin 眼膏](../supplies/medicines)。

</Info>

## 四、高发品种（侏儒型品种尤甚）

<Warning title="这些品种牙病风险最高">

因颅面紧凑（短吻、圆头），以下品种**牙病高发**，需更频繁检查：

- **荷兰侏儒兔**（Netherland Dwarf）—— 最严重，扁脸致牙齿拥挤
- **荷兰垂耳兔**（Holland Lop）
- **狮子兔**（Lionhead）
- **道奇兔**（Dutch）—— 下颌略长
- **霍托兔**（Dwarf Hotot）

详见各[品种页](../breeds/)。大型兔（Flemish Giant、新西兰白兔）牙病相对少。

</Warning>

## 五、在家自查（每周一次）

<FirstAidStep :num="1" title="看门齿（最容易）">

轻轻翻开上唇，看 4 颗上门齿：
- ✅ 颜色白/微黄、排列整齐、长度均匀
- ❌ 弯曲、过长、变色、缺角、流血

</FirstAidStep>

<FirstAidStep :num="2" title="摸下巴/面颊（查脓肿）">

用手指轻按下颌骨和面颊两侧：
- ✅ 对称、平滑
- ❌ 有硬块、凹凸不平、肿胀、兔表现疼痛

</FirstAidStep>

<FirstAidStep :num="3" title="观察进食行为">

- ✅ 正常咀嚼牧草（横向研磨动作）
- ❌ 食物从嘴里掉出（quidding）、只挑软食、吃草时显得费力/不适

</FirstAidStep>

<FirstAidStep :num="4" title="看日常信号">

- ❌ 流口水（下巴湿润/发红）
- ❌ 食欲下降、体重下降
- ❌ 反复流泪/眼分泌物
- ❌ 大声磨牙（疼痛信号，区别于满足时的轻磨牙——见[行为解读](./behavior)）

</FirstAidStep>

<Info title="臼齿在家很难看清">

门齿可以自查，但**臼齿（牙病最常发生处）需要兽医用耳镜/麻醉检查**。自查正常 ≠ 牙齿真的健康。仍需年度体检。

</Info>

## 六、何时必须就医

<VetCheck>

- 任何**门齿异常**（弯曲、过长、变色）
- **下巴/面部肿胀**或可触及硬块（脓肿）
- **流口水** + 拒食
- **食物从嘴里掉出**（quidding）
- **反复流泪/眼分泌物**（可能牙根连累鼻泪管）
- 兔**停止进食牧草**但还吃兔粮（可能臼齿尖刺疼痛）
- 任何疑似疼痛信号（蜷缩、大声磨牙、弓背）

</VetCheck>

## 七、兽医治疗（必须兽医操作）

- **麻醉下磨牙**：修剪过度生长的牙齿/尖刺。**绝不能在家自行剪**（牙根碎裂、感染）
- **拔牙**：严重受损或角度异常的牙齿
- **脓肿手术**：清创 + 长期抗生素
- **止痛**：牙病剧痛，必须镇痛（兽医处方）

## 八、预防：核心就是吃草

| 预防措施 | 为什么有效 |
|---|---|
| ✅ **无限量长牧草**（提摩西第一/二茬，茎多） | 提供横向研磨所需的粗长纤维——**唯一不可替代的磨牙方式** |
| ✅ **限量颗粒粮**（成兔每 2.25 kg 1/8–1/4 杯/天） | 防止兔"吃饱兔粮就不吃草" |
| ✅ **每年兽医体检**（侏儒品种每年 2 次） | 早发现 ADD |
| ✅ **选第一/二茬带茎的牧草** | 比第三茬软叶草更能磨牙 |
| ❌ 只喂兔粮/蔬菜 | 缺乏横向研磨 → 牙病必然发生 |
| ❌ 在家自行剪牙 | 牙根碎裂、感染 |
| ❌ 忽视"只吃兔粮不吃草" | 这是牙病的早期信号，不是挑食。纠正方法见[兔不爱吃草怎么办](../supplies/hay/) |

<Info title="用工具帮兔磨牙？">

市面上有"磨牙木/磨牙石/苹果枝"等零食。它们**可以丰富生活**，但**不能代替牧草磨牙**——兔咬这些是垂直咬碎，不产生臼齿所需的横向研磨。核心仍是无限量长牧草。

</Info>

## 九、一句话总结

<Warning title="养兔最关键的两个事实，绑定在一起">

1. **兔牙终生生长**（每周 2 mm），必须靠吃长牧草的横向研磨磨损
2. **颗粒粮不能代替牧草**——无论营养多全，都无法磨牙

**给兔无限量长牧草 = 同时解决消化健康 + 牙齿健康两个最关键问题。** 这就是为什么本站把它定为"养兔第一法则"。

</Warning>
