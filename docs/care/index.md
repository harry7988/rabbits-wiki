# 🏠 日常养育

兔兔是寿命 8–12 年的长期伴侣。科学的日常养育是**预防 90% 急症**的关键——绝大多数消化、生殖、行为问题都源于养育不当。

## 养育专题导航

### 健康管理（最优先）

- **[🦷 牙齿健康（吃草=磨牙）](./dental)** —— 牙病是胃肠停滞的头号隐性诱因，唯一预防是吃长草
- **[绝育与绝育后护理](./spay-neuter)** —— 为什么绝育是养兔的头等大事（母兔子官癌 >60%）
- **[幼兔养育（0–7 月龄）](./baby-rabbit)** —— 球虫预防、苜蓿草、社会化
- **[老年兔照护（5+ 岁）](./senior-rabbit)** —— 关节炎、体重监控、饮食调整

### 环境与陪伴

- **[新兔到家与适应期](./bringing-home)** —— 第一周的安静、空间、饮食过渡
- **[合笼（bonding）](./bonding)** —— 为什么建议成对饲养、如何安全合笼
- **[兔笼与环境丰容](./housing)** —— 笼子大小、垫料、玩具

### 行为与沟通

- **[兔兔行为解读](./behavior)** —— binky、跺脚、磨牙、喷尿标记
- **[定点如厕训练](./litter-training)** —— 兔可以学会用厕所

### 日常护理

- **[日常护理清单](./daily-care)** —— 梳毛、剪指甲、清耳、体检
- **[饮食配比](../supplies/hay/stage-ratio)** —— 见用品专题

## 一句话原则

> **预防胜于治疗**：无限量长牧草 + 限量颗粒粮 + 多样蔬菜 + 充足运动 + 减少应激 + 早期绝育 + 找好异宠兽医。

## 必须先知道的几件事

<Info title="兔兔不是『入门级宠物』，是 8–12 年的承诺">

兔兔需要：
- **专门的异宠兽医**（普通兽医可能不熟悉兔科）
- **大量空间**（不能关小笼子）
- **每日陪伴和运动**（至少 3–4 小时出笼）
- **高纤维饮食**（无限量牧草是必需，不是可选）
- **绝育**（健康和行为都需要）
- **长期承诺**（寿命堪比小型犬）

</Info>
