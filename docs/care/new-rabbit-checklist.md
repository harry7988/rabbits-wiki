# 🛒 新兔到家准备清单

<Info title="怎么用这份清单">

按"必需 → 进阶 → 避坑"三档。**先只买必需品**（预算 400–800 元），养两周确认兔的状态和你的节奏，再补进阶品。
带 <span class="cl-must-demo">必</span> 标记的是"没有会出事"的东西。

勾选进度存在你的浏览器里，可以边买边勾。

</Info>

## 三、不要买（常见坑）

<Danger title="这些东西买了反而害兔">

- **小笼子**——"侏儒兔专用小笼"是营销话术，笼子宁大勿小
- **muesli 混合粮**（带彩色颗粒/坚果/果干）——高糖高脂，兔会挑食
- **松木/雪松木屑垫料**——苯酚致肝损（详见[环境清洁](../handling/cleaning)）
- **凝结型猫砂**——兔会吃，致命
- **猫用化毛膏**——对兔有害无益（详见[化毛膏真相](../supplies/hairball-remedy)）
- **"兔用"酸奶球/奶制品零食**——兔乳糖不耐受，与致命肠毒血症相关
- **暴力牵引绳/背带**——兔受惊挣扎易脊柱骨折，不建议遛
- **磨牙石/盐砖**——磨牙要靠吃草不是石头；盐砖多余的钠
- **洗澡用品**——兔不需要洗澡，幼兔洗澡可致死
- **肉兔饲料**——为快速增重设计，成兔长期吃伤肾伤膀胱（详见[兔粮怎么选](../supplies/pellets)）

</Danger>

## 四、到家第一周怎么过

<FirstAidStep :num="1" title="前 3 天：只观察，少打扰">

提供原饮食（问前主人要同款粮草），安静环境。12 小时不吃不拉 = 急症。

</FirstAidStep>
<FirstAidStep :num="2" title="一周内：兽医体检 + 粪检">

带新鲜粪便做球虫检测（幼兔头号杀手）。

</FirstAidStep>
<FirstAidStep :num="3" title="隔离（家里已有兔）">

新兔必须隔离 2–4 周，不同房间 + 严格洗手。

</FirstAidStep>

详见[新兔到家与适应期](./bringing-home)。
