# 🏠 兔笼与环境丰容

<Warning title="传统『小笼子』对兔是虐待">

宠物店常卖的"兔笼"对成年兔**太小**。兔需要**至少 4 倍体长**的笼子 + 每日 3–4 小时出笼活动<cite><a href="#ref1">[1]</a></cite>。

</Warning>

## 一、空间需求

| 项目 | 最低要求 |
|---|---|
| **笼子/围栏大小** | ≥ 兔身长的 4 倍 × 2 倍宽 |
| **高度** | 兔能完全直立（用后腿站立） |
| **每日出笼时间** | ≥ 3–4 小时（理想：自由活动） |
| **跳台/多层** | 提供，给探索和俯视空间 |

<Info title="更好的方案：『兔屋』而非笼子">

很多有经验兔主人用 **大型 x-pen（宠物围栏）** 或 **整间兔屋** 代替笼子，给兔更多空间。兔是晨昏活动动物，需要空间跑跳。

</Info>

## 二、地板

<Danger title="铁丝网底笼 → 压疮（sore hocks）">

- ❌ **铁丝网底**——导致脚底压疮、感染，尤其大型兔和雷克斯
- ✅ **实心底** + 干草/稻草/木屑垫料
- ✅ 出笼活动区域提供**防滑地毯或瑜伽垫**（光滑瓷砖/木地板会导致脊柱受伤）

</Danger>

## 三、厕所设置

兔可以学会定点如厕（比猫还容易）：

<FirstAidStep :num="1" title="选大号厕所">

猫砂盆大小够兔整个身体进去。**角落型**猫砂盆适合。

</FirstAidStep>

<FirstAidStep :num="2" title="安全垫料">

- ✅ 纸质垫料、木浆颗粒、干草
- ❌ **松木/雪松木屑**（挥发油伤呼吸道）
- ❌ 凝结型猫砂（兔会吃，致命）

</FirstAidStep>

<FirstAidStep :num="3" title="干草架放厕所旁">

兔天性喜欢在厕所边吃草边尿——这是它们在野外隐藏气味的天性。

</FirstAidStep>

详见[定点如厕训练](./litter-training)。

## 四、温度与通风

| 因素 | 要求 |
|---|---|
| **适宜温度** | 15–25°C（>26°C 有热应激风险，见[中暑](../emergencies/heatstroke)）|
| **避免阳光直射** | 兔怕热 |
| **通风但无穿堂风** | |
| **湿度** | 40–60% |

## 五、环境丰容（防无聊）

<FirstAidStep :num="1" title="啃咬玩具">

苹果木、柳条编织物、未漂白纸板箱。**兔必须啃咬磨牙**，否则会啃家具/电线。

</FirstAidStep>

<FirstAidStep :num="2" title="隧道/纸袋">

兔爱钻洞。纸袋、PVC 隧道、布隧道都能用。

</FirstAidStep>

<FirstAidStep :num="3" title="可扔玩具">

婴儿玩具积木、未装东西的塑料瓶——兔爱用嘴扔着玩。

</FirstAidStep>

<FirstAidStep :num="4" title="遮蔽处">

纸箱、布帐篷——兔需要能躲的安全感。

</FirstAidStep>

<FirstAidStep :num="5" title="挖洞满足">

填满干草或碎纸的盒子，满足兔的挖洞天性。

</FirstAidStep>

## 六、安全（兔化你的家）

<Warning>

- **电线保护套**（必做！兔爱啃电线，触电致命）
- **遮蔽墙角/家具腿**（金属护角、PVC 管）
- **移走有毒植物**（见[中毒](../emergencies/poisoning)）
- **遮蔽狭缝**（兔能钻进 7cm 缝隙被困）
- **远离其他宠物**（猫狗 supervision）

</Warning>
