# 🏡 新兔到家与适应期

<Info title="前 7 天是应激高发期">

运输、新环境、新气味、新声音对兔都是巨大应激。应激会引发[GI Stasis](../emergencies/gi-stasis)，所以**第一周的核心是『减少刺激』**。

</Info>

## 一、到家前准备

<FirstAidStep :num="1" title="准备独立空间">

安静的房间，远离电视、小孩、其他宠物。一个**足够大**的笼子（≥ 4 倍兔体长）。

</FirstAidStep>

<FirstAidStep :num="2" title="询问前主人的饮食">

要一份**当前吃的兔粮品牌 + 牧草种类**。突然换粮会引发 GI 失衡。

</FirstAidStep>

<FirstAidStep :num="3" title="准备好异宠兽医">

新兔到家 1 周内做体检 + 粪便检测（球虫）。

</FirstAidStep>

## 二、到家第一周（应激管理）

<Warning title="前 3 天：尽量少打扰">

- 把兔放进笼子，**不要立即抱出**
- 让兔自己探索笼内空间
- 轻声说话，避免突然动作
- 维持原本饮食（同品牌兔粮 + 苜蓿/提摩西）
- **观察粪便和进食**——任何异常立即就医

</Warning>

<FirstAidStep :num="1" title="维持原饮食 2–4 周">

任何换粮都要 2 周过渡期：旧粮 75% → 50% → 25% → 新粮。

</FirstAidStep>

<FirstAidStep :num="2" title="每日观察">

- 粪便量、形状、颜色
- 是否正常进食饮水
- 精神状态
- 12 小时不吃不拉 = 急症

</FirstAidStep>

<FirstAidStep :num="3" title="3–7 天后开始温和互动">

坐地板上让兔主动靠近。不要强抓。

</FirstAidStep>

## 三、如果有其他兔：必须隔离

<Danger title="新兔必须隔离至少 2–4 周">

- 防止**球虫、螨虫、*E. cuniculi*、呼吸道感染**等传染给原住兔
- 不同房间，严格洗手
- 隔离期满 + 体检健康后再考虑[合笼](./bonding)

</Danger>

## 四、常见应激反应及处理

| 表现 | 含义 | 处理 |
|---|---|---|
| 躲藏、不动 | 正常应激反应 | 减少打扰，给遮蔽处 |
| 拒食 | **危险**（12 小时即急症） | 立即就医 |
| 跺脚 | 恐惧/警告 | 退后，给空间 |
| 软便（盲肠便）增多 | 应激导致菌群失衡 | 检查饮食纤维，必要时就医 |
| 磨牙（大声） | 疼痛 | 立即就医 |

## 五、适应进度（一般规律）

| 时间 | 进度 |
|---|---|
| 1–3 天 | 躲藏、应激，几乎不主动互动 |
| 1 周 | 开始探索笼外空间，接受手喂 |
| 2–4 周 | 习惯日常声响，开始主动互动 |
| 1–3 个月 | 完全适应，建立信任关系 |

<Info title="每只兔节奏不同">

有的兔 1 周就亲人，有的需要 3 个月。**不要比较，不要催促**。

</Info>
