# 🌡️ 量体温

<Info title="为什么养兔人必须会量体温">
兔体温异常是急症的关键信号：
- **体温 > 40.5°C**：[中暑](../emergencies/heatstroke)（致死性急症）
- **体温 < 38°C**：低温（休克、严重疾病、麻醉后）

GI Stasis 处置、中暑判断、术后恢复——都需要测体温。
</Info>

## 一、正常范围

**38.3–39.4°C（101–104°F）**

记住这两个阈值：
- **> 40.5°C / 104.9°F** = 中暑，立即急救<cite><a href="#ref1">[1]</a></cite>
- **< 38°C / 100.4°F** = 低温，需保温就医

## 二、直肠测温法（最准确）

### 工具
- **数字体温计**（儿童用，柔软尖端，约 ¥15-30）
- **水基润滑剂**（如 KY 凝胶 / Surgilube）
- 毛巾（保定）

### 步骤

<FirstAidStep :num="1" title="保定">
用 burrito 法包裹（见[保定](./restraining)），露出后臀。
</FirstAidStep>

<FirstAidStep :num="2" title="润滑">
体温计尖端**涂足量水基润滑剂**。
</FirstAidStep>

<FirstAidStep :num="3" title="轻柔插入">
一手轻抬兔尾，另一手将体温计**轻柔插入肛门约 1–1.5 cm**。遇到阻力不要强推。
</FirstAidStep>

<FirstAidStep :num="4" title="等待读数">
数字体温计通常 30–60 秒提示。期间一手稳住体温计，一手扶兔背安抚。
</FirstAidStep>

<FirstAidStep :num="5" title="清洁">
取出后用酒精棉片擦拭体温计。
</FirstAidStep>

<Warning>
- **不要用玻璃水银体温计**（兔挣扎时可能断裂，水银中毒 + 玻璃割伤）
- **不要强插**（阻力可能提示位置不对或兔紧张，强推会损伤直肠黏膜）
- 兔剧烈挣扎时**先停下**，休息后再试，或送兽医测
</Warning>

## 三、耳温/非接触测温

<Info title="耳温/额温枪不够准">
- **耳温枪**：兔耳道弯曲，探头难以对准鼓膜，读数**不稳定**
- **非接触红外额温枪**：测**耳尖皮肤温度**（耳朵是兔散热器官），**仅作粗略参考**——耳朵烫 = 可能中暑早期信号，但不能替代直肠测温做精确判断

日常可用**手摸耳朵**做快速筛查（中暑早期：耳朵发红、烫<cite><a href="#ref1">[1]</a></cite>），但精确诊断仍需直肠测温。
</Info>

## 四、温度计使用建议

- ✅ 专兔专用（交叉感染风险）
- ✅ 测前确认归零（数字体温计）
- ✅ 充足润滑
- ✅ 记录每次体温和测量时间（健康记录本，见[日常护理](../care/daily-care)）

## 五、体温异常的处理

### 高温（> 40.5°C）= 中暑

立即按[中暑处置](../emergencies/heatstroke)降温 + 送医：
- 转移阴凉处
- 用凉水（非冰水）打湿耳朵
- 同步送急诊

### 低温（< 38°C）

- 用**加热垫（低档）** 或体温取暖
- 包裹保暖
- **立即就医**（低温常提示严重疾病/休克）
