# 💊 喂药与强制喂食

<Danger title="喂药姿势错误会呛肺致死">

药液/流食误入气管 → **吸入性肺炎** → 可致死。

关键：**兔的头部必须高于尾部**（让其仰头吞咽），**少量多次**，**绝不强行灌入**<cite><a href="#ref1">[1]</a></cite>。

</Danger>

## 一、准备工作

<FirstAidStep :num="1" title="备齐物品">

- 无针头注射器（1 mL 给药 / 35 mL 导管尖喂 Critical Care）
- 药物（确认剂量、频次——遵兽医处方）
- 毛巾（用于 burrito 包裹，见[保定](./restraining)）
- 零食（喂药后奖励）

</FirstAidStep>

<FirstAidStep :num="2" title="确认药物剂型">

- **液体**：直接用注射器喂
- **药片**：可碾碎混少量果泥（无糖苹果泥）成糊，或直接塞入口腔后部
- **胶囊**：可打开撒入少量 wet food

</FirstAidStep>

<FirstAidStep :num="3" title="包裹保定（挣扎的兔）">

用毛巾包裹（[bunny burrito 法](./restraining)），露出头部。这能防止兔抓挠、乱动。

</FirstAidStep>

## 二、注射器喂液体药（最常见）

<FirstAidStep :num="1" title="姿势：兔头高于尾">

让兔**仰头**（朝上）——这样药液会流向咽部而非气管。

可坐姿把兔抱膝上，兔**背靠你胸**，头朝上。一手环抱固定。

</FirstAidStep>

<FirstAidStep :num="2" title="从嘴角侧面插入注射器">

**不要从正面塞**（兔会用舌顶住）。从**嘴角侧方**（犬齿后方）轻轻插入注射器尖端。

</FirstAidStep>

<FirstAidStep :num="3" title="少量慢推（关键！）">

- 每次推 **0.1–0.3 mL**（一小点）
- **等兔吞咽**（看喉部上下动）再推下一口
- 整个过程耐心——5 mL 可能要 2–5 分钟

</FirstAidStep>

<FirstAidStep :num="4" title="兔吐出来就重来">

药液被吐出不要急。擦掉，等兔平静，继续从嘴角少量喂。

</FirstAidStep>

<Warning title="呛肺的危险信号">

喂药后若兔出现：
- 咳嗽、打喷嚏
- 呼吸急促、费力
- 鼻孔有液体流出
- 精神迅速萎靡

**可能是吸入性肺炎——立即就医**。

</Warning>

## 三、喂药片

<FirstAidStep :num="1" title="碾碎法（首选）">

药片碾成粉，混入一小团**无糖苹果泥/南瓜泥**，搓成小球，让兔主动舔食。

</FirstAidStep>

<FirstAidStep :num="2" title="直接塞入法（碾碎无效时）">

- 一手从兔上方固定头部
- 另一手用钝头（如塑料药片切刀）将药片推入**口腔后部**（舌根处）
- 合上嘴，轻轻抚摸喉部帮助吞咽

</FirstAidStep>

<Warning>

**不要把药片混入水碗**——兔可能不喝完，剂量无法保证。

</Warning>

## 四、Critical Care 强制喂食（GI Stasis 关键）

GI Stasis 时兔不愿进食，必须强制喂食维持营养和肠蠕动<cite><a href="#ref2">[2]</a></cite>。

<FirstAidStep :num="1" title="调配">

**Oxbow Critical Care + 温水**，体积比 1:2，搅成稀糊状（不太稠，能从注射器流出）。

</FirstAidStep>

<FirstAidStep :num="2" title="工具">

**35 mL 导管尖注射器**（头部圆钝，不会戳伤口腔）。普通 1 mL 太慢。

</FirstAidStep>

<FirstAidStep :num="3" title="姿势">

兔背靠你胸，**头朝上**。一手环抱固定前肢。

</FirstAidStep>

<FirstAidStep :num="4" title="从嘴角侧方慢推">

每次推一小口（1–2 mL），等吞咽。参考日总量 **50 mL/kg/天，分 4–6 次**<cite><a href="#ref3">[3]</a></cite>。

</FirstAidStep>

<FirstAidStep :num="5" title="同步给水">

每次喂食后，用注射器喂少量水（防脱水）。

</FirstAidStep>

<Danger title="怀疑胃肠梗阻时绝对禁止强制喂食">

若兔**腹部坚硬如鼓**（怀疑梗阻），强制喂食会加重梗阻。必须兽医确诊后再喂。

</Danger>

## 五、兔剧烈挣扎怎么办

- **不要强灌**——呛肺风险极高
- 休息 5 分钟，让兔平静
- 检查包裹是否过紧（兔会因不适挣扎）
- 两人配合（一人抱一人喂）
- 实在喂不进——联系兽医（可能需要住院输液给药）

## 六、眼药/耳药

<FirstAidStep :num="1" title="保定">

用 burrito 包裹。眼药：一手固定头部；耳药：一手轻拉耳朵。

</FirstAidStep>

<FirstAidStep :num="2" title="滴入">

- **眼药**：滴在眼球表面（不是角膜中央），管口**不触眼**
- **耳药**：滴入耳道，轻揉耳根

</FirstAidStep>

<FirstAidStep :num="3" title="让兔眨眼/甩头">

不要立即松开保定，让药液停留几秒。

</FirstAidStep>

<Info title="眼病反复？查牙！">

兔的眼部问题多数根源在牙齿（牙根压迫鼻泪管）。详见[牙齿健康](../care/dental)。

</Info>
