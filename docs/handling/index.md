# 🤲 操作技能（动手养兔必备）

<Info title="为什么单独讲操作？">
急症时不会保定（控制）兔子、不会喂药、不会量体温——前面的急救知识就落地不了。

错误操作可能**直接致兔死亡**：
- 抱兔不当 → 后腿蹬踹 → **脊柱骨折**
- 喂药姿势错 → 药液入肺 → **吸入性肺炎**
- 喂 Critical Care 时头低于尾 → **呛肺**

这些技能必须**平时就练熟**，急症时才不会手忙脚乱。
</Info>

<Danger title="三个最危险的操作（必须学会）">
1. **[抱兔](./picking-up)** —— 错误抱法是脊柱骨折头号原因
2. **[喂药/强制喂食](./medicating)** —— 喂错姿势会呛肺致死
3. **[保定/包裹](./restraining)** —— 急症处置、剪指甲、喂药的前提
</Danger>

## 学习建议

<FirstAidStep :num="1" title="平时就练，不要等急症">
在兔健康时，每周做一次轻柔的"模拟训练"：摸耳朵、翻看门齿、轻按脚底、用空注射器碰嘴唇。让兔习惯被操作，急症时才不会剧烈挣扎。
</FirstAidStep>

<FirstAidStep :num="2" title="看视频 + 实操">
操作技能光看文字不够。本页每个技能都附了权威组织（HRS/RWAF）的视频教程链接，**先看视频再实操**。
</FirstAidStep>

<FirstAidStep :num="3" title="不确定就请兽医示范">
首次剪指甲、首次喂药——带兔去兽医那，请医生当面示范一次。这是最安全的学习方式。
</FirstAidStep>
