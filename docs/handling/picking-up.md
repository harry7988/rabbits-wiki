# 🐰 抱起与持有兔子

<Danger title="错误抱法是脊柱骨折的头号原因">

兔骨骼相对肌肉极轻。被抱起时若**后腿悬空 + 兔踢蹬挣扎**，扭转力可瞬间折断脊柱，导致**后腿永久瘫痪**（常需安乐）。

HRS 明确警告：**只抓颈背部（scruff）而不支撑后腿，兔踢蹬会导致脊柱骨折**<cite><a href="#ref1">[1]</a></cite>。

</Danger>

## 一、为什么兔天性怕被抱

<Info title="这不是『不爱我』，是猎物本能">

兔是**被捕食者**。在自然界，被"抱起空中"= 被猛禽抓走 = 死亡。

所以兔本能恐惧悬空——即便信任主人，被抱时仍会紧张。这是物种天性，不是个体性格问题。

多数兔**更喜欢四脚着地**被抚摸，而非被抱起<cite><a href="#ref2">[2]</a></cite>。

</Info>

## 二、正确的抱法（黄金法则）

<FirstAidStep :num="1" title="先让兔知道你要抱它">

不要从上方突然抓（像猛禽）。蹲下到兔的高度，从侧面接近，轻声说话，让兔看到你。

</FirstAidStep>

<FirstAidStep :num="2" title="一手托胸（前腿后方）">

把一只手放在兔胸前，**前腿后方**（不是压喉咙），手指环抱胸廓。

</FirstAidStep>

<FirstAidStep :num="3" title="另一手托臀（必须！）">

另一只手**托住兔的臀部后腿**——这是关键，**永远支撑后躯**，绝不能让后腿悬空。

</FirstAidStep>

<FirstAidStep :num="4" title="紧贴你的身体">

把兔**紧贴你的胸腹**——用你的身体作为脊柱的"夹板"（splint），减少脊柱受力<cite><a href="#ref3">[3]</a></cite>。

</FirstAidStep>

<FirstAidStep :num="5" title="保持低位">

尽量**坐着或蹲着抱**，不要站着抱。万一兔挣扎跳下，离地近伤害小。

</FirstAidStep>

## 三、绝对禁止的抱法

<Warning title="这些抱法可能致兔死亡">

- ❌ **只抓颈背部（scruff）不托臀** → 踢蹬致脊柱骨折<cite><a href="#ref1">[1]</a></cite>
- ❌ **抓耳朵** → 耳朵满布血管神经，剧痛 + 耳软骨损伤
- ❌ **抓四肢** → 骨折
- ❌ **悬空单手抱** → 无支撑，兔必挣扎
- ❌ **让兔趴你肩上** → 兔可能后跳，高处跌落
- ❌ **仰面朝上抱（除非医疗检查）** → 兔挣扎剧烈，脊柱受力大

</Warning>

## 四、让兔习惯被抱（训练）

<FirstAidStep :num="1" title="先让兔习惯被摸">

坐地板上，让兔主动靠近。摸额头、脸颊（兔喜欢）。建立"手 = 好事"。

</FirstAidStep>

<FirstAidStep :num="2" title="逐步接触">

轻轻把手放兔胸前（不抬起），给零食。让兔习惯"胸前有手"不恐惧。

</FirstAidStep>

<FirstAidStep :num="3" title="短时间抬起">

微微抬起 1-2 秒就放下，给零食。逐步延长。**永远托臀**。

</FirstAidStep>

<FirstAidStep :num="4" title="接受兔可能永远不爱被抱">

有的兔终其一生都不喜欢被抱。**尊重它**——在地面互动同样能建立深厚感情。

</FirstAidStep>

## 五、儿童与兔子

<Danger title="低龄儿童不应抱兔">

- 兔挣扎时儿童力量不足以控制 → 跌落 → 脊柱骨折
- 儿童动作不可控，可能伤兔或被咬
- 兔骨骼脆弱，"轻轻"跌落就是急诊

建议：**9 岁以下儿童只能在成人监督下、坐着、在地面与兔互动**，不主动抱<cite><a href="#ref2">[2]</a></cite>。

</Danger>

## 六、必须抱起的情况

有时不得不抱（看医生、转移、检查）。此时：
- 用**毛巾包裹**（见[保定/包裹](./restraining)）减少挣扎
- 动作稳、快、自信（犹豫会让兔更紧张）
- 抱起后立即贴近身体

## 七、何时不要抱

- 兔正在进食/如厕时（打扰会应激）
- 兔跺脚/躲闪/耳朵向后压（恐惧信号）
- 抽搐的兔（**绝对不要约束**，见[抽搐处置](../emergencies/seizures)）
- 怀疑脊柱骨折的兔（平硬表面搬运，见[骨折处置](../emergencies/fractures)）
