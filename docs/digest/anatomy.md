# 🔬 消化道解剖

兔（*Oryctolagus cuniculus*）是**单胃后肠发酵草食动物**（monogastric hindgut-fermenting herbivore）。它的消化道极为发达，约占体重的 **10–20%**<cite><a href="#ref1">[1]</a></cite>。

理解解剖结构，是理解后续所有"为什么"的基础。

## 一、消化道逐段路径

| 部位 | 主要功能 | 关键参数 | 食糜停留时间 |
|---|---|---|---|
| **口腔 / 牙齿** | 机械研磨，唾液润滑（淀粉酶活性低） | 28 颗恒齿，**终生持续生长** | — |
| **食道** | 单向运输（**无法逆蠕动**） | 强有力的贲门括约肌 | — |
| **胃** | 单室、薄壁的"储存罐"，**几乎永不排空** | 成年胃 pH 1–2；哺乳期幼兔 pH 5–6.5 | 3–6 小时 |
| **小肠**（十二指肠/空肠/回肠） | 胆汁+胰液稀释食糜；消化简单蛋白与碳水 | 空肠刷状缘吸收 | 约 1.5 小时 |
| **盲肠（Cecum）** | 厌氧"发酵罐"，微生物分解纤维素 | 最优盲肠 pH 5.7–6.1 | 2–12 小时 |
| **结肠**（近端 / **fusus coli** / 远端） | 颗粒分选；水、钠、钾重吸收 | **fusus coli 是"起搏器"** | — |
| **肛门** | 排出硬粪 / 直接摄食盲肠便 | 健康兔每日可排约 180 颗硬粪 | — |

<Info title="一个反直觉的事实">

兔的胃"**几乎永不排空**"——这是判断兔是否进食的重要临床线索。**空腹的兔胃本身就是病理信号**。这也是为什么"兔 12 小时不吃 = 急症"在解剖学上有明确依据<cite><a href="#ref1">[1]</a></cite><cite><a href="#ref2">[2]</a></cite>。

</Info>

## 二、重点：盲肠（Cecum）—— 兔的"发酵罐"

盲肠是一个**巨大的囊状厌氧发酵室**，是兔消化系统的核心<cite><a href="#ref2">[2]</a></cite>：

- 含 **74 种以上厌氧菌**（以 *Bacteroides* 为主），还包含杆菌、球菌、螺旋体、原虫等
- 微生物分解纤维素、尿素、蛋白，产生**挥发性脂肪酸（VFA：乙酸、丙酸、丁酸）**和菌体蛋白
- **VFA 提供兔约 40% 的维持能量需求**
- 盲肠内容物健康 pH 为 5.7–6.1，由丁酸调节

**当纤维不足或精料过多时**，盲肠 pH 偏离此区间，正常菌群被抑制，致病菌（如 *Clostridium* 梭菌）趁机增殖——这就是**肠毒血症**和很多消化道急症的根源<cite><a href="#ref2">[2]</a></cite>。

## 三、Fusus coli —— 结肠里的"起搏器"

兔的近端结肠有一段约 4 cm 长、富含黏液腺的特殊结构，叫 **fusus coli**。它受醛固酮和前列腺素调控，被兽医学界称为结肠蠕动的"**起搏器（pacemaker）**"——它决定食糜是被推向肛门排出硬粪，还是被反向推送回盲肠继续发酵<cite><a href="#ref2">[2]</a></cite><cite><a href="#ref3">[3]</a></cite>。

这一点是下一节"颗粒分选"机制的基础，理解了它就理解了为什么兔会按时排出两种完全不同的粪便。

## 四、牙齿结构与消化关系

<Warning title="牙病是 GI Stasis 最常见的隐性诱因之一">

兔牙痛 → 不愿咀嚼牧草 → 蠕动减慢 → 胃肠停滞。这条链条在临床极其常见。

</Warning>

兔的牙齿有四个关键事实<cite><a href="#ref4">[4]</a></cite><cite><a href="#ref5">[5]</a></cite>：

1. **齿式**：2 (I 2/1, C 0/0, P 3/2, M 3/3) = **28 颗恒齿**
2. **第二上门齿（peg teeth / "钉齿"）**：位于大门齿正后方的一对小钉齿——这是兔与啮齿类的关键区别
3. **所有牙齿均为 elodont（开放根）+ aradicular hypsodont（无真正牙根、长冠）**——**终身持续生长**，速率约 **2 mm/周**
4. **正确磨合并依赖粗长纤维（牧草）的研磨磨损**

如果饮食缺纤维 → 磨损不足 → 错颌畸形（malocclusion）/ 获得性牙病 → 疼痛 → 拒食 → GI Stasis。**这就是为什么"无限量供应长牧草"是兔饲养的第一法则**，颗粒粮无法替代（颗粒太小，无法提供磨牙所需的横向研磨）。详见 [🦷 牙齿健康专题](../care/dental)。

## 五、兔 vs 人类 / 猫 / 狗的关键差异

| 维度 | 兔 | 人类 / 狗 | 猫 |
|---|---|---|---|
| 消化策略 | **后肠发酵**（盲肠微生物） | 酶消化为主 | 酶消化为主（专性肉食） |
| 盲肠 | **巨大（发酵罐）** | 退化/小 | 小 |
| 食性 | **严格草食**（高纤维） | 杂食 | 严格肉食 |
| **食粪（cecotrophy）** | **有**（吃盲肠便） | 无 | 无 |
| 钙代谢 | **按摄入比例吸收，多余经尿排** | 按需吸收 | — |
| **呕吐能力** | **不能** | 能 | 能 |

这些差异决定了**绝对不能把猫狗的喂养/用药逻辑套用到兔身上**——这恰恰是很多致命事故的根源（详见[兔不能做的几件事](./key-traits)）。
