# 🚫 兔不能做的几件事

兔的生理与猫狗差异巨大。把猫狗的常识套用到兔身上，是很多致命事故的根源。本节讲**四个最关键的生理特性**。

## 一、兔不能呕吐

<Danger title="这意味着误食异物和毛球极其危险">

猫能吐毛球，**兔不能**。任何阻碍食糜通过的情况，都会导致胃迅速被液体和气体扩张 → 危及生命的**胃扩张**。

</Danger>

### 为什么兔不能呕吐（解剖学原因）

兽医学教科书对此有明确解释<cite><a href="#ref1">[1]</a></cite>：

1. **强有力的胃食管括约肌（贲门）**——作为单向阀门，阻止胃内容物反流
2. **食道平滑肌无法进行逆蠕动**——只能向胃方向单向推进
3. **膈肌脚环绕食管裂孔形成 "crural sling"**——额外的物理屏障
4. 缺乏有效的呕吐反射神经环路

### 三个直接的饲养含义

1. **绝对禁止催吐**——兔中毒后**绝不能像狗那样催吐**，既无效又危险（会导致误吸/窒息）
2. **毛球是结果而非原因**——这是养兔界最大的误区之一。详见[毛球症急症](../emergencies/hairball)
3. **误食异物极危险**——兔无法通过呕吐排出，常需手术

## 二、兔不能禁食

<Danger title="禁食 ≥ 12 小时即视为急症">

兔兔**停止进食或排便 12 小时或更久 = EMERGENCY**，必须立即就医。**禁食 ≥ 24 小时**可发展为**肝脂质沉积症（hepatic lipidosis，脂肪肝）**、严重代谢性酸中毒、肝衰竭，可致死<cite><a href="#ref2">[2]</a></cite><cite><a href="#ref1">[1]</a></cite>。

</Danger>

### 为什么兔不能像猫狗那样术前禁食

猫狗术前通常需禁食 8–12 小时以防麻醉时呕吐误吸。**兔绝不能这样处理**：

- 兔不能呕吐 → 麻醉时**本来就没有呕吐误吸风险**
- 兔胃"几乎永不排空" → 短时间禁食也无法真正清空胃
- 长时间禁食 → 触发 GI Stasis 恶性循环 → 麻醉风险反而上升

**正确的围手术期管理**：兔在术前、术中、术后都应**尽快恢复进食**，由熟悉兔科的异宠兽医制定方案<cite><a href="#ref1">[1]</a></cite>。

### 饲养含义

- "兔 12 小时不吃 = 急症"是养兔人必须牢记的**红线**
- 任何怀疑兔兔拒食（哪怕看起来还精神），都应**立即联系异宠兽医**，不要观望

## 三、兔不能随便用抗生素

<Warning title="某些常见抗生素对兔致命">

**口服青霉素及衍生物**（如阿莫西林 Amoxicillin）、**头孢类**、**林可霉素/克林霉素**等可破坏兔盲肠菌群，引发致命的**抗生素相关性肠毒血症**（由 *Clostridium spiroforme* 产 iota 毒素引起）<cite><a href="#ref1">[1]</a></cite>。

</Warning>

### 为什么

兔的盲肠是一个由 74+ 种厌氧菌构成的精密平衡生态系统，正常菌群通过**竞争性排斥**抑制致病菌。某些抗生素（尤其是口服、广谱、抗厌氧菌的）会破坏这套平衡，让致命梭菌爆发<cite><a href="#ref1">[1]</a></cite>。

### 饲养含义

- **任何对兔使用抗生素都必须由熟悉兔科的兽医开具**
- **绝不要自行给兔用人用药或猫狗药**
- 优先选择对兔盲肠菌群影响小的药物（如恩诺沙星、甲硝唑、复方磺胺等）——具体方案必须由兽医决定
- 不要觉得"上次剩的消炎药"就能用——剂量和种类对兔极其敏感

## 四、兔通过尿液排钙

<Info title="兔的钙代谢独一无二">

与大多数哺乳动物（按需吸收、激素精细调节）不同，**兔的肠道钙吸收几乎与摄入量成正比**——吃多少吸多少。多余的钙**主要经尿液排出**<cite><a href="#ref5">[5]</a></cite><cite><a href="#ref6">[6]</a></cite>。

</Info>

### 这意味着什么

- 兔尿呈**碱性**，钙与碳酸根结合形成**碳酸钙结晶**
- 高钙饮食时，尿钙排泄增加 → 尿液钙浓度升高 → 易形成结晶
- 沉淀为"**膀胱泥沙（sludge）**"，或聚结成**尿结石（uroliths）**<cite><a href="#ref7">[7]</a></cite>

### 高钙食物（成兔需控制频率和量）

- **苜蓿草**、苜蓿颗粒（这是为什么苜蓿只给幼兔/孕兔，成兔要避免）
- 高钙绿叶：**羽衣甘蓝（kale）、菠菜（spinach）、蒲公英叶、欧芹**、瑞士甜菜、菊苣

### 饲养含义

1. **成兔以提摩西草为主**（>80%），低钙
2. **限制高钙蔬菜**的频率和量
3. **鼓励大量饮水**（多个水碗、新鲜含水蔬菜）——这是预防膀胱泥沙最实际的办法
4. 出现**尿钙**（尿液浑浊、有白色沙粒残留）应及时咨询兽医
5. **不要给成兔额外补钙**或含钙的营养补充剂

<Info title="个体差异">

Oxbow 指出：有些长期高钙饮食的兔从不发病，有些正常/低钙饮食的兔也会发病——**遗传和水合状态也起作用**。所以"低钙饮食"是降低风险，不是绝对保证<cite><a href="#ref7">[7]</a></cite>。

</Info>

## 五、总结：兔的"四不一控"

| 不能 | 原因 | 实操 |
|---|---|---|
| **不能呕吐** | 强贲门括约肌 + 食道不可逆蠕动 | 中毒**禁止催吐**；毛球是结果非原因 |
| **不能禁食** | 胃几乎永不排空，禁食触发恶性循环 | **12 小时不吃 = 急症**；术前不禁食 |
| **不能乱用抗生素** | 破坏盲肠菌群 → 致命肠毒血症 | 一切抗生素**必须异宠兽医开具** |
| **不能像猫狗养** | 后肠发酵、严格草食、钙代谢独特 | 牧草为主，控制颗粒粮和高钙食物 |
| **控钙** | 多余钙经尿排出 → 膀胱泥沙/结石 | 成兔以提摩西为主，限制高钙蔬菜 |
