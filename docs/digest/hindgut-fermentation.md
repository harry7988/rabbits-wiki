# 🌿 后肠发酵与长纤维

上一节讲了盲肠是"发酵罐"。本节回答一个核心问题：**为什么必须给兔吃"长"牧草，颗粒粮不能代替？**

答案在于兔结肠里的一套精巧的**颗粒分选系统**。

## 一、后肠发酵（Hindgut Fermentation）原理

兔的前段消化（胃、小肠）与其他单胃哺乳动物相似——用酶消化简单蛋白和碳水化合物。但**纤维素的最终分解发生在盲肠**，这就是"后肠"发酵的含义<cite><a href="#ref1">[1]</a></cite>。

发酵产物——**挥发性脂肪酸（VFA）**——经盲肠壁吸收，提供兔**约 40% 的维持能量**<cite><a href="#ref2">[2]</a></cite>。

## 二、结肠的颗粒分选系统（关键）

兔结肠有一套**机械颗粒分选系统**，这是理解"为什么长纤维不可替代"的核心<cite><a href="#ref1">[1]</a></cite>：

- 结肠壁的囊状结构（haustra）**反向推送小颗粒（<0.3 mm）回到盲肠**继续发酵
- **大颗粒（>0.3 mm，尤其 >0.5 mm 的木质化纤维）被正向推送**，作为硬粪排出

```
食糜进入结肠
     │
     ├─ 小颗粒 (<0.3 mm) ──→ 反向推送回盲肠 ──→ 继续发酵 ──→ 产生 VFA
     │
     └─ 大颗粒 (>0.5 mm)  ──→ 正向推送 ──→ 形成硬粪排出
```

## 三、纤维的两种功能（教科书级分类）

| 类型 | 颗粒大小 | 营养价值 | 物理作用 |
|---|---|---|---|
| **不可消化纤维（粗长木质化颗粒 >0.5 mm）** | 大 | 无直接营养 | **刺激肠道蠕动**——这是"长纤维"不可替代的物理作用 |
| **可发酵纤维（小颗粒，半纤维素/纤维素）** | 小 | 进入盲肠发酵产 VFA | 提供能量 |

<Warning title="为什么颗粒粮和粉末化牧草不能替代长牧草">

如果纤维被磨得过细（如过多的颗粒粮、粉末化牧草、磨碎的草饼）：
1. 大颗粒（>0.5 mm）不足 → **结肠分选失效**
2. 盲肠内容物过度潴留 → "食糜堵塞（chymus jam）"
3. 发酵失衡，pH 偏移 → **致病菌（如 *Clostridium*）增殖**

颗粒粮的热量、维生素可以做到和牧草一样，但**它无法提供刺激肠道蠕动所需的"长纤维"物理刺激**。这就是为什么"无限量供应长牧草"是兔饲养的第一法则，没有例外<cite><a href="#ref1">[1]</a></cite>。

</Warning>

## 四、这个机制和"胃肠停滞（GI Stasis）"的关系

理解了颗粒分选，就理解了 GI Stasis 的核心驱动机制<cite><a href="#ref1">[1]</a></cite><cite><a href="#ref3">[3]</a></cite>：

1. 正常肠蠕动的**主要驱动力是大量不可消化纤维的存在**
2. 纤维不足或厌食 → 蠕动障碍
3. 蠕动停止 → 胃液被持续吸收 → 内容物脱水压实 → **疼痛**
4. 疼痛 → 进一步厌食（**恶性循环**）
5. 盲肠排空变慢 → *Clostridium* 等致病菌快速增殖 → 产气（胀气、剧痛）+ 释放致命毒素

**这就是为什么"换粮""突然减少牧草""应激拒食"能在 12 小时内演变成致命急症。**

<Info title="最新研究：菌群变化是『原因』还是『结果』？（诚实标注的争议）">

2025 年 PLOS ONE 一项对 43 只兔（21 健康 + 22 GI Stasis）粪便微生物组的研究发现，停滞组中 *Clostridium sensu stricto 1* 和某种肠杆菌科细菌增多，5 个有益菌属减少<cite><a href="#ref4">[4]</a></cite>。

**但研究作者明确指出：目前无法确定这些菌群变化是 GI Stasis 的"原因"还是"后果"。** 这是兽医学界正在研究的前沿问题，本站如实标注，不替读者下结论。

</Info>

## 五、实操结论

| ✅ 应该做 | ❌ 不应该做 |
|---|---|
| 成兔**无限量**供应提摩西草/果园草等长禾本科牧草 | 用颗粒粮"代替"牧草 |
| 选**第一、二茬**带茎的提摩西草（颗粒大、纤维长） | 只喂柔软多叶的第三茬（纤维不足） |
| 颗粒粮按体重限量（成兔每 2.25 kg 约 1/8–1/4 杯/天） | 把颗粒粮当主食 |
| 提供多种禾本科牧草（果园草、燕麦草）增加多样性 | 喂大量水果、淀粉、面包等高碳水零食 |
| 每天观察粪便量和形状 | 忽视"粪便变小、变少"的早期信号 |

详细的牧草选择、品质鉴别、各阶段配比，见[常备药与用品 → 牧草专题](../supplies/hay/)。
