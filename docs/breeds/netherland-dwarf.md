# 🐇 荷兰侏儒兔 Netherland Dwarf

<BreedCard
  name="荷兰侏儒兔 Netherland Dwarf"
  weight="1.1–2.5 lbs（ARBA 上限 2.5 lbs / 1.13 kg）—**ARBA 最小认可品种**"
  lifespan="10–12 年"
  origin="荷兰"
  temperament="初时易害羞/紧张/胆小；建立信任后亲人；聪明可训练"
  grooming="短被毛，每周梳理一次，换毛期隔日梳理；立耳少需清耳；指甲 4–6 周一修"

## 一、外观

- **圆球型（cobby）**、苹果大头
- **<2.5 英寸立耳**、大眼

## 二、关键：颅面/牙齿问题最突出

<Warning title="扁脸 + 短吻 → 牙齿拥挤高发">
荷兰侏儒兔是**牙齿和上呼吸道问题最高发**的品种之一<cite><a href="#ref1">[1]</a></cite>：

- **malocclusion（咬合不正）**——牙齿拥挤
- **牙根向上长入鼻腔** → 炎症
- **上呼吸道感染（URI）** 高发
- GI Stasis、*Cheyletiella* 螨、*E. cuniculi*

**饲养含义**：必须提供**大量长牧草**自然磨牙，每年请兔科兽医检查牙齿数次。
</Warning>

## 三、侏儒基因 dw 与伦理

荷兰侏儒兔携带**侏儒基因 dw（隐性致死等位基因）**<cite><a href="#ref2">[2]</a></cite>：

| 基因型 | 表型 | 结局 |
|---|---|---|
| DwDw | 假侏儒 | 正常体型，健康 |
| Dwdw | 真侏儒 | 紧凑、展会理想型 |
| dwdw | peanut | **致死**，出生数日内死亡 |

两个真侏儒交配，**每胎统计上 25% 为 peanut**。详见 [品种总览](./)。

## 四、适合人群

- **成人、年长者**
- **不建议有低龄儿童的家庭**——体型太小，易因不当抓握或跌落受伤<cite><a href="#ref1">[1]</a></cite>

## 五、警惕"茶杯兔"骗局

<Danger>
荷兰侏儒兔已是 ARBA 最小认可品种（2.5 lbs）。任何宣称『比荷兰侏儒兔更小的茶杯兔』都是**营销噱头**——可能是未断奶幼兔、营养不良个体或近亲繁殖产物。详见 [品种总览辟谣](./)。
</Danger>
