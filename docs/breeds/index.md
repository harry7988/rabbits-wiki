# 🐇 兔品种百科

## 一、关于品种标准

本站的品种体重、外形、认可色等"硬数据"，以 **ARBA（美国兔业繁殖者协会，arba.net）** 的官方品种标准为首要依据<cite><a href="#ref1">[1]</a></cite>。ARBA 目前认可 **50 个兔品种**（不含豚鼠 cavy）。

健康、寿命、疾病倾向则引用 **House Rabbit Society（rabbit.org）** 与 **PetMD（DVM 审核）**。

## 二、按体型分类（ARBA 官方）

| 体型 | 特征 | 常见品种 |
|---|---|---|
| **Compact（紧凑型）** | 短、圆、紧凑——最常见宠物体型 | 荷兰垂耳、荷兰侏儒、狮子、Mini Rex、Dutch |
| **Commercial（商业型）** | 肉用体型，中到大型 | 新西兰白兔、银狐、佛罗里达白 |
| **Full-arch（全拱型）** | 站立时背线呈拱形，活泼 | 巨型花兔、Belgian Hare |
| **Cylindrical（圆柱型）** | 细长蛇形 | Himalayan |
| **Mandolin（曼陀林型）** | 大型，背线后段隆起 | Flemish Giant、French Lop |

## 三、常见宠物兔品种速查

| 品种 | 体重（ARBA） | 性格 | 适合人群 |
|---|---|---|---|
| [荷兰垂耳兔 Holland Lop](./holland-lop) | ≤ 4 lbs（1.8 kg） | 温顺、亲人、活泼 | 家庭、9 岁以上儿童 |
| [荷兰侏儒兔 Netherland Dwarf](./netherland-dwarf) | ≤ 2.5 lbs（1.13 kg）—**最小** | 初期害羞、聪明 | 成人；不建议低龄儿童 |
| [狮子兔 Lionhead](./lionhead) | 0.74–1.7 kg | 聪明、社交 | 能每日梳毛的家庭 |
| [迷你雷克斯 Mini Rex](./mini-rex) | ≤ 4.5 lbs（2.0 kg） | 温顺、好奇 | 首次饲主 |
| [安哥拉兔 Angora](./angora) | 6–10+ lbs | 温顺但需大量护理 | **有经验**的纤维爱好者 |
| [道奇/熊猫兔 Dutch](./dutch) | ≤ 5.5 lbs（2.5 kg） | 聪明、友好、可训练 | **首次饲主首选** |

## 四、必须辟谣的中文市场概念（重要）

### 茶杯兔 / 微型兔 —— 不存在此品种

<Danger title="世界上不存在被任何权威机构认可的『茶杯兔』品种">

事实<cite><a href="#ref2">[2]</a></cite><cite><a href="#ref3">[3]</a></cite>：
- 『茶杯兔/微型兔』**不是品种，而是营销标签**
- **全球最小的认可家兔品种是荷兰侏儒兔**（ARBA 上限 2.5 lbs / 1.13 kg），已无更小的认可品种
- 北美最小的**野生**兔种（哥伦比亚盆地侏儒兔）是**联邦濒危物种**，**不能作为宠物**

商家把以下个体当『茶杯兔』出售，是欺骗：
1. **未断奶的幼兔**（宣称『成体不变大』）
2. **营养不良/发育迟缓的成兔**
3. **近亲繁殖**的瘦小个体
4. 携带**双侏儒基因（dw/dw）** 的『peanuts』——本应夭折的个体被强行养大

</Danger>

SPCA、House Rabbit Society 等福利组织明确警告：**为追求极端小体型而选育是不道德的**，伴随牙齿、骨骼、消化与寿命问题<cite><a href="#ref3">[3]</a></cite>。

### 熊猫兔 —— 容易混淆两个品种

<Warning>

在中国宠物市场，『熊猫兔』是**泛称**，可能指两种完全不同的品种<cite><a href="#ref4">[4]</a></cite>：

| 实际品种 | 外观 | 区分特征 |
|---|---|---|
| **道奇兔 Dutch** | 白 + 黑/棕双色，**分体"八字"图案**，鞍形白带 | **分体双色** |
| **霍托兔 Hotot / Dwarf Hotot** | **全白身体 + 仅眼周黑环**（"熊猫眼"） | **纯白 + 眼环** |

购买前务必看清是哪一种，二者体型、性格、护理需求都不同。

</Warning>

### 迷你兔 / Mini —— 注意区分

<Info>

**ARBA 认可的『Mini』品种**（Mini Rex、Mini Lop、Mini Satin）是**有明确体重上限的认可品种**。

这与商家自定义的『迷你/微型』营销词含义**完全不同**。看到"迷你"时，问清楚是 ARBA 认可品种还是商家营销词。

</Info>

### 侏儒基因与繁育伦理（侏儒品种专题）

<Warning title="所有侏儒型品种的繁育天然伴随 25% 早期死亡率">

侏儒基因 **dw** 是**隐性致死等位基因**<cite><a href="#ref5">[5]</a></cite>。两个真侏儒（Dwdw）交配，每胎统计上 **25% 为 "peanut"（dwdw）**，出生数日内死亡。

| 基因型 | 表型 | 结局 |
|---|---|---|
| DwDw | 假侏儒 | 正常体型，健康 |
| Dwdw | 真侏儒 | 紧凑、展会理想型 |
| dwdw | peanut | **致死**，数日内死亡 |

这是购买/繁殖荷兰侏儒、荷兰垂耳、狮子兔等品种时**应客观了解的事实**。

</Warning>

## 五、选品种前的核心建议

1. **不要为追求小体型而支持不道德繁育**（茶杯兔、过小个体）
2. **优先领养**——救助机构有大量各品种兔等待领养
3. **空间匹配**——大型兔（新西兰白兔、银狐、Flemish Giant）需要大型围栏
4. **护理时间匹配**——长毛兔（安哥拉、狮子兔双鬃）必须每日梳毛
5. **家庭成员匹配**——体型太小的侏儒兔不建议低龄儿童家庭（易受伤）
6. **认准 ARBA 标准**——商家营销词（茶杯/微型/超小）不等于品种标准
