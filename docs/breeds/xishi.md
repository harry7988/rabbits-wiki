# 🐇 西施兔 / 凤眼西施兔（市场名消歧）

<Info title="先说结论：这是一个市场名，不是一个品种">

“西施兔”“凤眼西施兔”**不是任何国际品种登记机构（如 ARBA、BRC）认可的品种名**——ARBA 认可的 53 个兔品种中没有“西施兔”<cite><a href="#ref1">[1]</a></cite>。它是中文宠物市场的**商品命名习惯**：把长毛、毛发覆脸飘逸的兔子按“西施”命名；眼周有明显色圈（像画了眼线的丹凤眼）的个体被叫做“**凤眼西施兔**”<cite><a href="#ref2">[2]</a></cite>。

</Info>

## 一、你买到的“西施兔”通常是什么

中文市场的“西施兔”指**长毛种宠物兔**，百科词条描述其成年体重约 2–2.2 kg、全身毛发飘逸<cite><a href="#ref2">[2]</a></cite>。从外观特征看，这类兔子的血统通常接近以下三类：

| 你家兔子的特征 | 血统可能接近 | 详细照护 |
|---|---|---|
| 立耳、体型偏大（4 lbs+）、羊毛浓密到盖住脸和耳 | [安哥拉系](./angora)（国内毛用长毛兔产业以安哥拉血统为主） | 毛球预防是生死问题 |
| 立耳、小体型（≤3.5 lbs）、大头短耳、毛量中等 | [泽西长毛兔（市场也叫“猫猫兔”）](./jersey-wooly) | 相对好打理的长毛 |
| **垂耳** + 长毛、紧凑体型 | [美种费斯垂耳兔（市场也叫“猫猫兔”）](./american-fuzzy-lop) 或其混血 | 梳毛 + 垂耳护理 |
| 以上特征混杂、体型介于中间 | **长毛混血**（最常见） | 按下面的通用长毛照护 |

“**凤眼**”指眼周有深色毛圈——观感与[霍托兔（眼环）](./hotot)的黑色眼环相似，但西施兔是长毛种；这是商家对特定花色个体的加价命名，**与品种、健康、性格都无关**。

## 二、长毛兔照护要点（不管它叫什么名字）

<Warning title="长毛兔的三件事，做不好会出命">

- **日常梳理**——长毛打结后会牵拉皮肤、藏污纳疾；换毛期每日梳理（物理除毛是最重要的防毛球手段，详见[安哥拉兔页](./angora)）
- **毛球梗阻是长毛兔头号杀手**——高纤维饮食（提摩西草无限量）+ 充足饮水；**不要用化毛膏**（见[化毛膏争议](../supplies/hairball-remedy)）
- **红线**：停止进食或排便达 **12 小时即急症**，立即就医（见[胃肠停滞](../emergencies/gi-stasis)）

</Warning>

夏季还要注意长毛兔的**中暑风险**（见[中暑处置](../emergencies/heatstroke)）——长毛 + 高温是危险组合，不可自行剃光（兔皮肤薄，易剃伤）。

## 三、购买提醒

<Danger title="“凤眼西施兔”式的命名是营销话术">

- “西施兔”“凤眼西施兔”“公主兔”等都是**商家起的好听名字**，不是品种承诺——同类案例见[茶杯兔辟谣](./)
- 为“凤眼”眼圈花色支付溢价没有意义：花色与健康、性格无关
- 兔子**不会因为名字里带“侏儒/迷你/西施”就长不大**——按上表判断成年底盘，准备好对应体型的笼位和食量
- 领养渠道的长毛兔同样适用本页的判断与照护方法

</Danger>
