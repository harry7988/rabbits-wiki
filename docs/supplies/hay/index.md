# 🌾 牧草专题

牧草是兔兔饮食的**绝对核心**，占成兔饮食的 80–85%。理解为什么"必须吃草、不能只吃粮"，请先读 [后肠发酵原理](../../digest/hindgut-fermentation)。

## 子页面

- [提摩西草 Timothy Hay](./timothy) —— **成兔黄金标准主食**，纤维 30–34%，三茬区别
- [苜蓿草 Alfalfa](./alfalfa) —— **幼兔/孕兔专用**，高钙高蛋白，成兔避免
- [牧草品质鉴别](./grading) —— 颜色/气味/含水率/产地，绝对禁忌发霉草
- [各阶段牧草配比](./stage-ratio) —— 综合饮食金字塔，幼/成/老年兔配比

## 一句话原则

> **成兔：无限量提摩西草 + 限量颗粒粮 + 多样蔬菜 + 极少水果。**

<Info title="为什么不能『以粮代草』">
颗粒粮的热量、维生素可以做到和牧草一样，但**它无法提供刺激肠道蠕动所需的"长纤维"物理刺激**。颗粒粮代替牧草 → 结肠颗粒分选失效 → 盲肠菌群失衡 → GI Stasis。详见 [后肠发酵原理](../../digest/hindgut-fermentation)。
</Info>
