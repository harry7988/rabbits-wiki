# 🌾 牧草专题

牧草是兔兔饮食的**绝对核心**，占成兔饮食的 80–85%。理解为什么"必须吃草、不能只吃粮"，请先读 [后肠发酵原理](../../digest/hindgut-fermentation)。

## 子页面

- [提摩西草 Timothy Hay](./timothy) —— **成兔黄金标准主食**，纤维 30–34%，三茬区别
- [苜蓿草 Alfalfa](./alfalfa) —— **幼兔/孕兔专用**，高钙高蛋白，成兔避免
- [牧草品质鉴别](./grading) —— 颜色/气味/含水率/产地，绝对禁忌发霉草
- [各阶段牧草配比](./stage-ratio) —— 综合饮食金字塔，幼/成/老年兔配比

## 一句话原则

> **成兔：无限量提摩西草 + 限量颗粒粮 + 多样蔬菜 + 极少水果。**

<Info title="为什么不能『以粮代草』">

颗粒粮的热量、维生素可以做到和牧草一样，但**它无法提供刺激肠道蠕动所需的"长纤维"物理刺激**。颗粒粮代替牧草 → 结肠颗粒分选失效 → 盲肠菌群失衡 → GI Stasis。详见 [后肠发酵原理](../../digest/hindgut-fermentation)。

</Info>

## 兔不爱吃草怎么办（挑食纠正）

这是兔主人最常见的问题之一。**先说最重要的**：

<Danger title="先排除健康原因，再当挑食处理">

**突然不吃草**（之前吃得好好的）往往不是挑食，而是**牙病的信号**——臼齿尖刺让咀嚼疼痛，兔会避开需要研磨的牧草、只挑软食（兔粮/蔬菜）。这本身就是就医信号，详见[🦷 牙齿健康](../../care/dental)。

- **突然拒草** → 按急症对待（12 小时不吃不拉 = 急诊）
- **一直不太爱草、挑着吃** → 可以用下面的策略纠正

</Danger>

### 纠正策略（按优先级）

<FirstAidStep :num="1" title="减少颗粒粮（最有效）">

兔粮吃饱了自然不吃草。把量减到标准下限（每 2.25 kg 体重 1/8 杯/天），甚至短期再少一点——**健康的兔饿一点会去吃草，但草必须随时有**。用[喂食计算器](../../tools/)算标准量。

</FirstAidStep>

<FirstAidStep :num="2" title="换草试试">

- **换茬次**：三茬软叶适口性好（但纤维低）——先用三茬勾起兴趣，再逐步混入一/二茬
- **换品种**：果园草、燕麦草、草地草轮着来，很多兔各有偏好
- **换新鲜度**：陈草适口性差很多。开封超过 1–2 个月的草，兔可能就是不爱吃
- **混搭**：新草 + 旧草混合，逐步提高新草比例

</FirstAidStep>

<FirstAidStep :num="3" title="改变放草的位置和方式">

- **草架放厕所边**——兔天性边吃边拉，这是最自然的组合（详见[定点如厕](../../care/litter-training)）
- **多个位置放草**：笼里、活动区、它常趴的角落
- **直接撒一撮在地上**：有些兔不爱从草架里拉草
- **塞进纸筒/草球玩具**：边玩边吃

</FirstAidStep>

<FirstAidStep :num="4" title="不要用这些方法">

- ❌ **加零食引诱**——治标不治本，还养成更挑
- ❌ **饿到不吃就换粮**——兔长期不吃草的后果比挑食严重得多
- ❌ **只喂蔬菜顶替**——蔬菜不能提供长纤维

</FirstAidStep>

### 底线

无限量新鲜牧草 + 限量兔粮 + 耐心。大多数挑食的兔在"粮减量 + 草新鲜 + 位置对"三招下会在几周内好转。**始终不吃** → 查牙。
