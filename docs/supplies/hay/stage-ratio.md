# ⚖️ 各阶段牧草配比

综合 HRS、VCA、Rabbit Resource 共识的饮食金字塔<cite><a href="#ref1">[1]</a></cite><cite><a href="#ref2">[2]</a></cite>。

## 一、综合饮食金字塔（成兔标准）

```
                ┌──────────┐
                │  水果零食 │  每周 ≤1–2 次，每次每 2 lb 约 1 茶匙
                ├──────────┤
                │  颗粒粮   │  成兔每 2.25 kg 体重 1/8–1/4 杯/天
                ├──────────┤
                │ 新鲜绿叶菜│  每天 1–4 杯（多样混合）
                ├──────────┤
                │  牧草 + 水 │  ★ 无限量（占饮食 80–85%）★
                └──────────┘
```

## 二、各阶段详细配比

### 幼兔（<7–8 月龄）

| 项目 | 配比 |
|---|---|
| **苜蓿草** | **无限量** |
| **苜蓿基础颗粒粮** | 无限量 |
| 绿叶蔬菜 | 少量多样（逐步引入） |

> 过渡：7 月龄起**逐步**（2–4 周）从苜蓿过渡到提摩西。

### 成兔（>7 月龄）

| 项目 | 配比 |
|---|---|
| **提摩西草/其他禾本科草** | **无限量（占饮食 80–85%）** |
| **提摩西基础颗粒粮** | 每 5 lb（2.25 kg）体重 1/8–1/4 杯/天 |
| **新鲜绿叶蔬菜** | 每天 1–4 杯（多样混合） |
| 水果 | 每周 ≤1–2 次，每次每 2 lb 约 1 茶匙（零食） |

### 老年兔（>5–6 岁）

- 维持提摩西为主
- 体重下降者可少量补充苜蓿或燕麦草（兽医指导下）

## 三、绝对禁忌（所有阶段）

<Danger>

- ❌ 饼干、坚果、种子
- ❌ 谷物、面包、面食
- ❌ 巧克力、咖啡因
- ❌ 高糖零食（市售"兔用酸奶糖珠"等多数含糖过高）
- ❌ 鳄梨（avocado）—— 对兔有毒
- ❌ 洋葱、大蒜、韭菜
- ❌ 土豆、土豆芽

</Danger>

## 四、合适的蔬菜（成兔）

### 日常可喂（多样混合）
- 生菜（**非卷心莴苣 iceberg**，营养低）
- 芹菜（切段）
- 黄瓜
- 甜椒（去籽）
- 茴香
- 香菜、罗勒、薄荷等香草

### 高钙蔬菜（**控制频率和量**，防膀胱泥沙）
- 羽衣甘蓝（kale）
- 菠菜（spinach）
- 蒲公英叶
- 欧芹
- 瑞士甜菜

<Warning title="高钙蔬菜不是不能喂，而是控制">

详见[钙代谢](../../digest/key-traits)。成兔高钙饮食会增加膀胱泥沙风险，但完全不吃蔬菜也不对——多样、轮换、控量即可。

</Warning>

## 五、合适的水果（零食，极少量）

- 苹果（**去籽**——籽含氰苷）
- 草莓、蓝莓、覆盆子
- 香蕉（极少，高糖）
- 木瓜、菠萝（**注意：木瓜酶"化毛"缺乏科学证据**，详见[化毛膏争议](../hairball-remedy)）

## 六、关键原则

1. **牧草 > 一切**——无限量长牧草是健康基础
2. **颗粒粮限量**——过量是 GI 失衡和肥胖的常见原因
3. **多样蔬菜**——提供丰富维生素和水分
4. **糖分严格限制**——兔的盲肠不适应高糖
5. **任何换粮都要 2 周过渡**——突然改变会引发 GI Stasis
