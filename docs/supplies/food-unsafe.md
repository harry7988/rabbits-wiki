# ⛔ 兔子不能吃什么

<Danger title="误食了怎么办">
兔**不能呕吐**，催吐既无效又危险。任何误食：
1. 立即移走剩余食物，**记下名称/分量/时间**
2. **不要**自行催吐、喂奶、喂活性炭
3. 联系异宠兽医——Oxbow 明确建议：误食以下任何食物，**无论量多少都应联系兽医**<cite><a href="#ref1">[1]</a></cite>

详见[中毒与误食处置](../emergencies/poisoning)。
</Danger>

## 一、有毒（可致命）

| 食物 | 毒素 / 危害 |
|---|---|
| **巧克力 / 可可** | 可可碱 + 咖啡因，越黑毒性越强，可致命<cite><a href="#ref1">[1]</a></cite> |
| **鳄梨 / 牛油果** | persin 毒素，呼吸困难甚至心力衰竭<cite><a href="#ref1">[1]</a></cite> |
| **洋葱 / 大蒜 / 韭菜 / 韭葱**（生熟都算） | 破坏红细胞 → 溶血性贫血<cite><a href="#ref1">[1]</a></cite> |
| **水果籽和核**：苹果籽、梨籽、桃核、樱桃核、李核 | 含氰苷，咀嚼后释放氰化物；**果肉可喂、籽核去掉**<cite><a href="#ref1">[1]</a></cite> |
| **生土豆**（及土豆芽） | 茄碱 + 高淀粉<cite><a href="#ref1">[1]</a></cite> |
| **大黄（rhubarb）** | 高浓度草酸，干扰钙代谢<cite><a href="#ref1">[1]</a></cite> |
| **蘑菇** | 霉菌毒素风险，生熟都不宜<cite><a href="#ref1">[1]</a></cite> |
| **蚕豆 / 芸豆** | 高碳水 → 腹泻、胀气、菌群紊乱<cite><a href="#ref1">[1]</a></cite> |

## 二、不该喂（伤身）

| 食物 | 为什么 |
|---|---|
| **肉 / 蛋 / 乳制品**（含酸奶球零食） | 兔是严格草食动物，动物蛋白毁盲肠菌群；乳糖不耐受<cite><a href="#ref1">[1]</a></cite> |
| **面包 / 饼干 / 薯片 / 米面** | 高碳水高糖 → 肠道菌群失衡、肥胖，可引发致命性肠毒血症<cite><a href="#ref1">[1]</a></cite> |
| **坚果 / 种子** | 脂肪过高；带壳碎粒有误吸风险 |
| **卷心莴苣（iceberg）** | 含 lactucarium 且几乎无营养，大量吃有害<cite><a href="#ref1">[1]</a></cite> |
| **含糖饮料 / 人类零食** | 一律不给 |
| **猫狗粮** | 蛋白脂肪配方完全不适合兔 |

## 三、容易误以为能给的

- **"兔爱吃胡萝卜"** → 胡萝卜是**高糖零食**不是主食（动画片误导），当蔬菜少量给
- **猫用化毛膏** → 对兔有害（油基让毛球防水），见[化毛膏真相](./hairball-remedy)
- **"吃点酸奶助消化"** → 乳制品是禁忌，益生菌问题见[益生菌专题](./probiotics)
- **人用维生素/钙片** → 脂溶性维生素蓄积中毒，不要自行补

## 四、家里和户外的植物

很多常见植物有毒（百合、杜鹃、绿萝、常春藤、风信子球根……）——
用我们的[有毒植物查询器](../tools/)查，每条带 Cornell/HRS 来源。

户外注意：**喷过农药/杀虫剂的草不能采**，剪草机碎草会发酵产气，不要喂。
