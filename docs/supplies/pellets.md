# 🌾 兔粮如何选择

<Info title="本页核心立场">
很多营销号把"含 X 成分 = 有毒"一刀切，**这是反科学的**。任何成分的"有害性"必须结合**剂量、工艺、营养配比**讨论。

本页所有判断基于：
- **FEDIAF（欧洲宠物食品联合会）2024 兔营养指南**——现行最权威基准
- **NRC（美国国家研究委员会）《兔营养需要》**
- **Merck 兽医手册**
- **中国国标** GB 10648《饲料标签》、GB 13078《饲料卫生标准》、LS/T 3408《肉兔配合饲料》
- **香港消委会** 12 款兔粮独立测试
</Info>

<Danger title="兔粮只是『补充』，不是主食">
兔粮**永远不能代替牧草**。成兔饮食结构：
- **牧草 80–85%**（无限量，提供长纤维刺激蠕动——见[后肠发酵原理](../digest/hindgut-fermentation)）
- **兔粮 5–10%**（限量，每 2.25 kg 体重 1/8–1/4 杯/天）
- **新鲜蔬菜**，每天 1–4 杯

兔粮的作用是补充牧草中不足的维生素、矿物质和部分蛋白——**不是热量的主要来源**。
</Danger>

## 一、营养标准（基准）

### 国际现状（重要：AAFCO 没有兔标准）

| 标准 | 状态 |
|---|---|
| **AAFCO（美国）** | **营养档案仅覆盖犬、猫**，兔/小型草食动物未列入。美国兔粮按"饲料"标签法规管理（粗蛋白/脂肪标 min，粗纤维/水分标 max）<cite><a href="#ref-aafco">[AAFCO]</a></cite> |
| **NRC（1977）** | 《Nutrient Requirements of Rabbits》第二版仍是基础，但近 50 年未更新专册<cite><a href="#ref-nrc">[NRC]</a></cite> |
| **FEDIAF（2024-11）** | **现行最权威**的兔营养指南，给出 RA（推荐量）与 SUL（安全上限）<cite><a href="#ref-fediaf">[FEDIAF]</a></cite> |

### FEDIAF 2024 成兔维持期核心营养（每 kg 饲料，含水量 12%）

| 营养素 | 推荐范围（RA） | 安全上限（SUL） | 备注 |
|---|---|---|---|
| **粗蛋白** | 12–17% | — | 过量→肠紊乱；赖氨酸是第一限制性氨基酸 |
| **粗脂肪** | ~2.5%（上限 5%） | — | 高脂→肥胖 |
| **淀粉+糖** | ≤13.5% | — | **关键红线**——防肠毒血症 |
| **粗纤维** | ~25%（维持期典型） | — | 粗纤维 ≠ 总膳食纤维，需结合 ADF/NDF |
| **钙** | 0.4–0.5% | **1.0%** | 兔钙代谢独特：吸收近乎无调节，经尿排出（见[钙代谢](../digest/key-traits)）|
| **磷** | 0.5–0.8% | — | >0.9% 抑制繁殖性能 |
| **钙磷比** | 1.5:1–2:1 | — | 失衡→牙病 |
| **钠** | 0.2–0.6% | — | <0.2% 影响氨基酸吸收 |
| **铜** | 5 mg/kg（典型） | 法定上限 | 兔对铜敏感，过量肝蓄积 |
| **维生素 A** | 6000–10000 IU/kg | — | NRC/Merck 给更宽范围 5000–75000 IU/kg |
| **维生素 D3** | 800–1000 IU/kg | **2000 IU/kg** | 过量→软组织钙化，不可逆；**不要自行补充** |
| **维生素 E** | 50–160 mg/kg | — | 缺乏致肌肉萎缩 |

<Warning title="兔粮标注的『粗纤维』可能误导">
"粗纤维"（CF）只是 Weende 法测的一部分（占真纤维 20–90%）。更准确的指标：
- **ADF**（酸性洗涤剂纤维）= 纤维素 + 木质素 = 不可消化纤维
- **NDF**（中性洗涤剂纤维）= 半纤 + 纤 + 木 = 总纤维

兔需要的是**长颗粒不可消化纤维**（>0.5 mm）刺激蠕动。看兔粮时，CF ≥18% 是基础，但还要看配料表第一位是不是真正的牧草<cite><a href="#ref-merck">[Merck]</a></cite>。
</Warning>

### 中国国标现状（重要：法规真空）

<Danger title="国内『宠物兔粮』不属于『宠物饲料』！">
中国《宠物饲料管理办法》（农业农村部公告第 20 号）**第二十七条明确：仅适用于宠物犬、宠物猫**，其他宠物饲料"另行规定"——但至今未出台<cite><a href="#ref-gb20">[GB 20]</a></cite>。

这意味着：
- **国内"宠物兔粮"无专门强制国标**
- 按传统畜禽饲料框架管理，须符合 GB 13078 卫生标准 + GB 10648 标签
- **GB 13078 明确"不适用于宠物饲料产品"**——存在监管真空<cite><a href="#ref-gb13078">[GB 13078]</a></cite>
- "肉兔料冒充宠物兔料"现象有法规根源
</Danger>

相关国标：
| 标准 | 内容 |
|---|---|
| **GB 10648-2013《饲料标签》** | 配料表按重量**降序**排列；须标"成分分析保证值"<cite><a href="#ref-gb10648">[GB 10648]</a></cite> |
| **GB 13078-2017《饲料卫生标准》** | 黄曲霉毒素 B1 ≤20 μg/kg；管砷/铅/镉/汞等——但**不约束宠物饲料** |
| **LS/T 3408-1995《肉兔配合饲料》** | 育肥料：蛋白≥14–16%、纤维 10–14%、钙 0.5–1.0%——**为肉兔快速增重设计，不适合宠物兔**<cite><a href="#ref-lst3408">[LS/T 3408]</a></cite> |

<Info title="为什么本表对『玉米/小麦』标限量而不是避免？">
这正好回应你强调的"不抛开剂量谈问题"。Blas 1994 经典研究证明：**总日粮淀粉 ≤13.5% 是关键**，而非"含玉米/小麦 = 有毒"。

- Oxbow Essentials 配料第二位是 Soybean Hulls（大豆荚），不是玉米
- 即便配料含小麦（如 Mazuri Timothy 含 Wheat Middlings），只要总淀粉不超 13.5%，对兔是安全的
- 真正要避免的是配料表第一位是谷物（说明配方以淀粉为基础）
</Info>

## 三、维生素与矿物质：过量比缺乏更危险

<Warning title="脂溶性维生素（A、D、E、K）会蓄积中毒">

| 维生素 | 缺乏症 | 过量症 | 安全范围 |
|---|---|---|---|
| **维 A** | 流产、胎儿脑积水、新生兔死亡 | **与缺乏症状相同**——流产、脑积水 | NRC/Merck：5000–75000 IU/kg（区间宽）|
| **维 D3** | 牙/骨/肌问题、贫血、免疫低下 | 高血钙、动脉/肝/肾软组织钙化，**不可逆** | 800–1000 IU/kg；**SUL 2000 IU/kg** |
| **维 E** | 肌肉萎缩、不孕 | 出血 | 50–160 mg/kg |

**关键**：
- 维 D 过量比缺乏更危险。**主人绝不要自行补充维 D**——会致命<cite><a href="#ref-vitd">[Univ. Missouri CVM]</a></cite>
- 维 A 过量与缺乏症状相同——这是反直觉但重要的医学事实<cite><a href="#ref-vita">[DiGiacomo 1992]</a></cite>
- 香港消委会测试发现 3 款主食维 D3 1082–1729 IU/kg，超 RA 上限但低于 SUL<cite><a href="#ref-consumer">[消委会]</a></cite>
</Warning>

## 五、选购原则（清晰可执行）

适用于**成兔（>7 月龄、已绝育、室内饲养）**。幼兔/孕泌乳兔见后。

### 看配料表

1. ✅ **第一位是牧草**（提摩西/果园草/燕麦草），不是谷物
2. ✅ 无玉米/小麦作为主要配料（位次靠后可接受）
3. ✅ 无人工色素、人工调味剂
4. ✅ 防腐剂用天然生育酚（mixed tocopherols），不用乙氧基喹
5. ✅ 均匀单一颗粒（extruded 或 cold-pressed），**避免 muesli 混合粮**

### 看成分分析保证值

| 指标 | 成兔理想范围 | 备注 |
|---|---|---|
| **粗纤维** | ≥18%（理想 22–25%） | 越高越好（前提是配料真为牧草）|
| **粗蛋白** | 12–16% | 过高加重肾脏/盲肠负担 |
| **粗脂肪** | ≤5%（理想 2.5–4%） | |
| **钙** | 0.4–0.6% | 上限 1.0%；泌尿问题兔选 ≤0.5% |
| **钙磷比** | 1.5:1–2:1 | |
| **淀粉+糖** | ≤13.5% | 多数国产料不标，需问客服或第三方测试 |

### 按年龄选基础

- **幼兔（<7 月）、孕泌乳兔**：**苜蓿基础**（高钙高蛋白）
- **成兔（>7 月）**：**提摩西基础**（低钙）
- 详见 [各阶段牧草配比](./hay/stage-ratio)

### 饲喂量

- 成兔：**每 2.25 kg（5 lb）体重 1/8–1/4 杯/天**
- **牧草无限量**
- 不要"看到碗空就加"——肥胖是室内兔常见问题

## 六、八大误区辟谣

<Danger title="这些『常识』都是错的">

| 误区 | 真相 |
|---|---|
| **『纯天然无添加就是好』** | 无防腐剂的饲料易霉变，**霉菌毒素（黄曲霉毒素，兔限 5 ppm）远比合规防腐剂危险** |
| **『配料表越短越好』** | 看具体配料——维矿物质预混料是必要的，不能一刀切 |
| **『高蛋白就是好营养』** | 成兔高蛋白加重肾脏和盲肠负担；FEDIAF 上限 17% |
| **『维生素越多越好』** | 脂溶性维 A/D 蓄积中毒（维 D SUL 2000 IU/kg）|
| **『国产都是差，进口都是好』** | 香港消委会测的进口大牌（VETAFARM、MOMI、WOOLY）多项不达标；看具体配方 |
| **『颜色深的更天然』** | 颜色 ≠ 营养；人工色素对兔毫无必要 |
| **『零食混合粮适合日常』** | 高糖高脂，仅偶尔作训练零食 |
| **『肉兔料便宜也能喂宠物兔』** | 肉兔料为快速增重设计（蛋白 16–18%、钙 0.8–1%+），成兔长期吃致胖/尿石/肾负担 |
| **『玉米/小麦有毒』** | **剂量决定毒性**；总日粮淀粉 ≤13.5% 是关键，而非单一谷物 |
| **『大豆有抗营养因子禁用』** | 经过热处理的豆粕是常规安全蛋白源 |
| **『兔需要乳制品补钙』** | 兔乳糖不耐受，yogurt drops 与致命性肠毒血症相关 |
| **『散装更划算』** | 三无产品无质检、易霉变、配料不明 |

</Danger>

<Info title="『肉兔料』和『宠物兔料』的根本区别">
**肉兔料**（如 LS/T 3408-1995）为**快速增重**设计：
- 蛋白 16–18%、钙 0.8–1.0%+、纤维仅 10–14%
- 寿命目标：3–4 个月出栏

**宠物兔料**为**长期健康**设计（参考 FEDIAF）：
- 蛋白 12–14%、钙 0.4–0.6%、纤维 ≥18%（理想 22%+）
- 寿命目标：8–12 年

**长期给室内宠物兔喂肉兔料 → 肥胖、膀胱泥沙/尿石、肾负担**。法规上肉兔料证照也不能标注"宠物配合饲料"<cite><a href="#ref-lst3408">[LS/T 3408]</a></cite>。
</Info>
