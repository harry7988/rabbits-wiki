# 💊 家庭药箱清单

根据 House Rabbit Society、Rabbit Advocates、Oxbow 等权威组织的急救包建议，将兔子常用物品按"是否需兽医指导"**分级**<cite><a href="#ref1">[1]</a></cite><cite><a href="#ref2">[2]</a></cite>。

## A 级：家庭非处方常备（安全，送医前可作应急）

| 物品 | 用途 |
|---|---|
| **婴儿西甲硅油（Simethicone）** | [胀气](../emergencies/gi-stasis)；无色无味型 |
| **Oxbow Critical Care / Sherwood Recovery Food** | 拒食时强制喂食 |
| **无味 Pedialyte** | [脱水/腹泻](../emergencies/diarrhea)补电解质 |
| **生理盐水** | 冲洗眼/伤口 |
| **Nolvasan（氯己定）** | 清洁伤口 |
| **普通 Neosporin/Polysporin**（**不含止痛/皮质类固醇**） | 浅表伤口 |
| **止血粉 / 玉米淀粉** | 指甲出血 |
| **数字温度计** + 水基润滑剂 | 正常体温 38.3–39.4°C / 101–104°F |
| **无针头注射器**（1 mL、5 mL、35 mL 导管尖） | 给药/喂食 |
| **纱布、VetWrap 自粘绷带、棉签** | 伤口处理 |
| **毛巾** | 保定用 |
| **加热垫/冰袋** | **必须先量体温再用** |

## B 级：非处方但需谨慎（短期应急，症状持续必须就医）

| 物品 | 用途 | 注意 |
|---|---|---|
| **Bene-Bac Plus 凝胶** | [益生菌](./probiotics) | 见争议页；无糖无乳制品配方 |
| **Terramycin 眼膏** | 浅表眼感染应急 | 详见[常备药品](./medicines)；眼病多与牙病相关，必须就医 |
| **三联抗生素软膏** | 轻微割伤 | **必须选"不含止痛"版本** |

## C 级：处方药（必须兽医开具，绝不要自行使用）

| 物品 | 用途 |
|---|---|
| **促动力药（Metoclopramide）** | GI Stasis（兽医指导下） |
| **止痛药（Meloxicam）** | 疼痛管理 |
| **球虫药（Toltrazuril/Diclazuril）** | [球虫病](../emergencies/coccidiosis) |
| **驱虫药（Fenbendazole）** | *E. cuniculi*、肠道寄生虫 |
| **皮下输液（LRS）** | 严重脱水（必须兽医操作） |

<Danger title="所有 C 级药物必须由兔科兽医开具">

兔药物安全窗极窄，许多猫狗常用药对兔致命（口服青霉素/阿莫西林、头孢类、Micotil）<cite><a href="#ref3">[3]</a></cite>。

</Danger>

## D 级：明确禁忌（不要进你家）

| 物品 | 为什么禁忌 | 详见 |
|---|---|---|
| ❌ **猫用化毛膏（Petromalt/Laxatone）** | 油基润滑剂使毛球防水、更难排出 | [化毛膏争议](./hairball-remedy) |
| ❌ **矿物油** | 同上 | [化毛膏争议](./hairball-remedy) |
| ❌ **含止痛/皮质类固醇的 Neosporin Plus** | 类固醇对兔严重免疫抑制 | [外伤处置](../emergencies/wounds) |
| ❌ **人用运动饮料（佳得乐等）** | 含糖和添加剂过高 | [电解质](./electrolytes) |
| ❌ **含糖酸奶"宠物益生菌"** | 糖分滋养有害菌 | [益生菌](./probiotics) |
| ❌ **任何未经兽医确认的剂量** | 兔药物安全窗极窄 | [常备药品](./medicines) |

## 急救包配置建议

<Info>

按上面的 A 级清单配置一整套家庭急救包，放在固定位置，全家都知道在哪。**24 小时异宠急诊兽医的联系方式**贴在急救包上和冰箱上。

换毛期前补充：指甲剪、长毛兔专用梳、电推剪（长毛兔）。

</Info>
