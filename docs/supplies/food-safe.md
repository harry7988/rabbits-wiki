# 🥬 兔子能吃什么

<Info title="先记住结构，再记清单">
成兔每天的食物就四样，比例不能乱：

1. **牧草（提摩西等禾本科）**：无限量，占 80–85%
2. **新鲜绿叶蔬菜**：每天每 2.25 kg（5 lb）体重约 1 杯起，**至少 3 种轮换**
3. **颗粒粮**：限量，每 2.25 kg 体重 1/8–1/4 杯
4. **水果**：只当零食，每 1 kg 体重约每天 1 茶匙<cite><a href="#ref1">[1]</a></cite>

一句话：**草管饱、菜多样、粮限口、果点缀**。详细原理见[各阶段饮食配比](./hay/stage-ratio)。
</Info>

## 一、每天可以吃的蔬菜（绿叶类）

每天至少 3 种轮换，切碎混合<cite><a href="#ref1">[1]</a></cite>：

| 蔬菜 | 说明 |
|---|---|
| 生菜（罗马/红叶/绿叶） | ❌ 不是卷心莴苣（iceberg，无营养） |
| 蒲公英叶 | 高钙，成兔控制频率 |
| 芝麻菜（火箭菜） | |
| 香菜 | 多数兔很爱 |
| 罗勒 / 薄荷 / 牛至 | 香草类，气味重的少量试 |
| 菊苣 / 苦菊 | |
| 水芹（西洋菜） | |
| 油麦菜 / 小白菜 | 中文市场好买 |
| 芹菜 | 切段，丝会缠牙 |
| 小麦草 | 自己种最划算 |

**高钙蔬菜（要轮换限量，防膀胱泥沙）**：羽衣甘蓝、菠菜、欧芹、甜菜叶、瑞士甜菜、蒲公英——
每天 3 种绿叶里**最多 1 种**来自这类，且别天天同一种<cite><a href="#ref1">[1]</a></cite>。原理见[钙代谢](../digest/key-traits)。

## 二、非绿叶蔬菜（少量点缀）

每天不超过新鲜部分的 15%（约每 1 kg 体重 1 汤匙）<cite><a href="#ref1">[1]</a></cite>：

- 甜椒（去籽，任何颜色）
- 西兰花（叶和茎；个别兔会胀气，少量试）
- 胡萝卜（**当蔬菜不是水果**，含糖不低）
- 西葫芦
- 抱子甘蓝、卷心菜（都可能胀气，少量）
- 黄瓜（水分高，夏天好）
- 食用花卉（玫瑰花瓣、旱金莲、万寿菊）

## 三、水果（零食，严格限量）

每 1 kg 体重约每天 **1 茶匙**，或每周 1–2 次一小块<cite><a href="#ref1">[1]</a></cite>：

| 水果 | 处理要点 |
|---|---|
| 苹果 | **去籽去核**（籽含氰苷） |
| 香蕉 | 去皮，高糖极少量 |
| 草莓 / 蓝莓 / 树莓 | 整颗可喂，洗净 |
| 樱桃 | **去核** |
| 葡萄 | 去籽品种更省事，对狗有毒但对兔无碍的量级仍按零食算 |
| 猕猴桃 / 芒果 / 木瓜 | 去皮 |
| 桃 / 李 | **去核** |
| 梨 | **去籽去核** |
| 瓜类（西瓜/哈密瓜） | 瓜皮也可啃，高糖少量 |
| 菠萝 | 鲜果少量；"菠萝酶化毛"是伪科学，见[化毛膏真相](./hairball-remedy) |

## 四、绝对的主食：牧草

蔬菜水果只是配菜。**没有牧草，上面一切都没有意义**——
牧草同时承担磨牙和维持肠蠕动，兔粮替代不了。详见[提摩西草](./hay/timothy)和[🦷 牙齿健康](../care/dental)。

## 五、喂新食物的原则

<FirstAidStep :num="1" title="一次只加一种">
连喂 2–3 天观察粪便，软便/腹胀就停。
</FirstAidStep>
<FirstAidStep :num="2" title="洗净">
蔬菜至少流水洗 2 分钟（防农药和 RHDV2 传播风险）<cite><a href="#ref1">[1]</a></cite>。
</FirstAidStep>
